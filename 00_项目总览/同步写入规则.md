# 同步写入规则

本文件用于约定研究协作过程中，哪些内容需要同步写入项目文档。

## 一、可直接同步写入的内容

以下内容可以根据讨论结果直接写入项目文件夹：

1. 研究路线和技术方案。
2. 数据来源、数据字典、数据核查记录。
3. 模型设定、参数表、公式草案和方法说明。
4. 文献阅读笔记和参考文献整理。
5. 代码说明、运行记录、结果解释。
6. 论文结构、摘要草稿、引言草稿、方法草稿。
7. 决策点清单和会议纪要。

## 二、需要负责人确认后再写入为“最终选择”的内容

以下内容可以先形成建议，但最终选择必须由负责人确认：

1. 研究尺度：全国、州级、城市级或重点州。
2. 数据Y口径：probable cases、confirmed cases 或其他口径。
3. 时间范围：是否纳入 2026 年不完整数据。
4. 气候变量：温度、降雨、湿度、滞后周数等。
5. 模型复杂度：基线模型、气候敏感模型、多区域模型或最优控制模型。
6. 参数估计方法：最小二乘、泊松似然、负二项似然、贝叶斯方法。
7. 目标期刊和投稿方向。
8. 论文最终结论和公共卫生建议。

| 论文草稿 | `06_论文与报告/00_手稿` |
| 决策记录 | `09_项目管理` |

## 四、同步写入原则

1. 所有不确定信息必须标注为“待确认”。
2. 不把未经核查的数据、参数或结论写成确定事实。
3. 负责人未确认的选择，只能写入“建议方案”或“候选方案”。
4. 真实数据来源必须记录 URL、下载日期、口径和版本。
5. 每次形成重要研究判断，都应同步到对应 Markdown 文档。
6. 已经形成的关键决策，应同步写入 `00_项目总览/研究决策总档案.md`，作为持续更新的主档案。
7. `研究决策总档案.md` 使用 Markdown + TeX 公式维护；正式阅读时通过 Markdown Preview Enhanced 或阅读版 HTML 查看渲染后的公式。
8. `研究决策总档案_阅读版.html` 是阅读展示文件，不作为主要编辑源；主编辑源始终是 `研究决策总档案.md`。
