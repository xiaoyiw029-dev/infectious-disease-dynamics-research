# 巴西基孔肯雅热动力学建模研究执行总方案

## 一、研究定位

本项目以巴西基孔肯雅热为研究对象，目标不是单纯画病例曲线，而是建立一个可以被数据校准、可以解释传播机制、可以进行短期预测和干预情景比较的传染病动力学研究框架。

建议将研究分为三层推进：

1. 基线层：使用巴西周尺度病例数据，建立宿主-媒介耦合 SEIR-蚊媒模型，完成拟合与短期预测。
2. 气候扩展层：将温度、降雨等气候变量引入传播率或蚊媒参数，比较模型预测能力是否提升。
3. 干预评估层：设置灭蚊、减少蚊虫叮咬、病例管理等控制变量，进行情景模拟或最优控制分析。

## 二、优先研究问题

建议优先回答以下问题：

1. 巴西基孔肯雅热周病例在 2015-2026 年间呈现怎样的季节性和年份差异？
2. 人群-蚊媒耦合模型能否较好拟合周尺度病例曲线？
3. 温度、降雨等气候因子是否能解释传播强度的季节波动？
4. 哪些参数对基本再生数或累计病例数最敏感？
5. 在模型框架下，灭蚊、减少叮咬、病例管理等措施对疫情峰值和累计病例的影响有多大？

## 三、建议技术路线

### 阶段 1：数据链路建立

- 下载并备份 OPENDATASUS/SINAN 基孔肯雅热数据。
- 下载并备份 INMET 历史气象数据。
- 获取 IBGE 人口数据，用于发病率和初始易感人群规模设定。
- 建立数据字典，明确每个字段的含义、单位和缺失值处理方式。

### 阶段 2：描述性分析

- 按流行病学周汇总病例。
- 区分全国尺度、州尺度或重点州尺度。
- 绘制周病例、累计病例、发病率、季节性热图。
- 检查异常周、缺失周、报告延迟和重复记录。

### 阶段 3：基线动力学模型

建议先建立宿主-媒介耦合模型：

人群：

- S：易感者
- E：潜伏感染者
- I：感染者
- R：康复者

蚊媒：

- X：易感蚊
- Y：潜伏期蚊
- Z：感染性蚊

核心耦合机制：

- 感染性蚊叮咬易感者，使人群从 S 进入 E。
- 易感蚊叮咬感染者，使蚊媒从 X 进入 Y。
- 潜伏蚊完成外潜伏期后进入感染性蚊 Z。

### 阶段 4：参数估计与预测

参考猴痘模型论文的思路：

- 部分生物学参数来自文献，例如人潜伏期、感染期、蚊媒寿命、外潜伏期。
- 关键传播参数通过病例数据拟合。
- 使用非线性最小二乘、负二项似然或泊松似然进行参数估计。
- 将数据划分为训练集和测试集，进行短期预测检验。

建议先用非线性最小二乘作为入门版本；当病例数据过度离散明显时，再升级为负二项似然。

### 阶段 5：敏感性分析

局部敏感性分析：

- 使用归一化前向敏感性指数。
- 输出每个参数对 R0、峰值病例、累计病例的影响方向和大小。

全局敏感性分析：

- 使用 Latin Hypercube Sampling (LHS)。
- 使用 PRCC 评估参数与输出指标之间的关系。

### 阶段 6：气候敏感扩展

可选嵌入方式：

1. 让蚊到人的传播率随气候变化：beta_mh(t) = f(T, P)。
2. 让人到蚊的传播率随气候变化：beta_hm(t) = f(T, P)。
3. 让蚊媒死亡率或出生率随气候变化：mu_v(t), Lambda_v(t)。
4. 使用滞后气候变量，例如前 1-4 周降雨和温度。

建议先使用简单可解释函数：

```text
beta_mh(t) = beta0 * exp(a_T * T_lag + a_P * P_lag)
```

或者：

```text
beta_mh(t) = beta0 * (1 + a_T * standardized_temperature + a_P * standardized_rainfall)
```

是否使用非线性温度响应函数，应等基础结果稳定后再决定。

### 阶段 7：干预模拟或最优控制

初始建议先做情景模拟：

- 提高蚊媒死亡率：模拟灭蚊。
- 降低叮咬率或传播率：模拟驱蚊剂、蚊帐、环境治理。
- 提高病例发现和管理效率：模拟缩短感染期。

若论文需要更强数学理论深度，再扩展为最优控制：

- 控制变量 u1(t)：降低蚊-人接触或叮咬。
- 控制变量 u2(t)：提高蚊媒死亡率。
- 控制变量 u3(t)：降低人到蚊传播。
- 控制变量 u4(t)：提高病例管理或恢复率。

目标函数可综合感染人数和控制成本。

## 四、当前最关键的决策

以下问题需要负责人最终决定：

1. 研究尺度：全国、州级，还是选择 3-5 个重点州？
2. 病例口径：使用 probable cases，还是 confirmed cases？
3. 时间范围：使用 2015-2025 完整年度，还是加入 2026 年不完整数据？
4. 气候匹配：用全国平均气候、州级气候，还是站点-行政区空间匹配？
5. 模型复杂度：先做基线模型，还是一开始就做气候敏感模型？
6. 参数估计方法：先用最小二乘，还是直接用泊松/负二项似然？
7. 最终产出重点：偏数学理论、偏真实数据预测，还是偏公共卫生政策解释？

## 五、推荐当前行动

建议现在优先完成三件事：

1. 确定研究尺度和病例口径。
2. 下载并检查 OPENDATASUS 数据字典和 2015-2026 年病例数据。
3. 建立第一版周病例时间序列，先做描述性分析图。

完成这三件事后，再进入模型方程和参数估计。
