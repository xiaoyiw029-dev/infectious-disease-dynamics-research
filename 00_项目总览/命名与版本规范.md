# 命名与版本规范

## 文件命名

推荐格式：

```text
YYYYMMDD_研究主题_内容说明_v版本号.扩展名
```

示例：

```text
20260806_SEIR模型_模型设定_v01.md
20260806_数据Y数据_清洗说明_v02.md
20260806_Rt估计_图2源数据_v01.csv
```

## 版本号

- `v01`：初稿或首次生成版本。
- `v02`、`v03`：有实质性修改。
- `final`：仅用于已经提交、发表或冻结的版本。

## 数据版本

每个数据版本应记录：

- 数据来源
- 获取日期
- 时间范围
- 纳入和排除规则
- 清洗脚本
- 生成者
- 变更摘要

## 代码版本

建议每次关键分析记录：

- 运行日期
- 代码文件或提交编号
- 输入数据版本
- 输出结果位置
- 软件环境
- 运行者

## 图表版本

正式图表建议同时保存：

- 图表源数据
- 生成代码
- 可编辑源文件
- 导出图片或PDF
- 图注和统计说明
