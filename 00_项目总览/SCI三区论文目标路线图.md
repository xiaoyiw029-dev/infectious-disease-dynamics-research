# SCI 三区论文目标路线图

## 一、目标判断

当前项目具备冲击 SCI 三区论文的潜力，但不能停留在常规的“建立仓室模型、计算 R0、做稳定性分析、最小二乘拟合、敏感性分析、最优控制”套路。

更稳妥的论文定位应为：

```text
真实多源数据驱动的巴西基孔肯雅热气候敏感宿主-媒介动力学建模、短期预测与干预情景评估。
```

## 二、建议主创新点

### 创新点 1：真实多源数据融合

整合：

- OPENDATASUS/SINAN 基孔肯雅热周病例数据。
- INMET 温度、降雨、湿度等气象数据。
- IBGE 人口数据。

形成可复现的巴西基孔肯雅热建模数据集。

### 创新点 2：气候敏感宿主-媒介耦合模型

在 SEIR-蚊媒模型基础上，将温度、降雨等气候变量嵌入传播率或蚊媒生态参数，解释季节性传播强度变化。

建议比较三类模型：

1. 无气候基线模型。
2. 季节性传播率模型。
3. 气候滞后驱动模型。

### 创新点 3：预测验证

不只做全样本拟合，而要设置训练集和测试集，评估短期预测能力。

推荐指标：

- RMSE。
- MAE。
- MAPE 或 sMAPE。
- 峰值周误差。
- 峰值规模误差。
- 累计病例误差。

### 创新点 4：关键驱动因素识别

通过局部敏感性分析和 LHS-PRCC 全局敏感性分析，识别影响传播阈值、疫情峰值和累计病例的关键参数。

### 创新点 5：防控情景评估

优先做现实可解释的情景模拟：

- 灭蚊。
- 清除孳生地和环境治理。
- 减少蚊虫叮咬。
- 病例管理，降低感染期被蚊叮咬概率。

最优控制作为增强项，而不是第一版必须完成项。

## 三、不建议作为唯一创新点的内容

以下内容可作为方法组成部分，但不宜单独作为论文核心创新：

1. 仅建立一个 SEIR 或 SEIR-蚊媒模型。
2. 仅计算 R0。
3. 仅证明无病平衡点稳定。
4. 仅用最小二乘拟合病例数据。
5. 仅做局部敏感性分析。
6. 仅套用最优控制框架。

这些内容在传染病动力学论文中较常见，若没有真实数据、气候机制或预测验证支撑，创新性不足。

## 四、推荐论文题目方向

中文工作题目：

```text
基于周尺度监测数据与气候因子的巴西基孔肯雅热宿主-媒介动力学建模、预测与干预评估
```

英文工作题目：

```text
Climate-sensitive host-vector transmission modeling, forecasting, and intervention assessment of chikungunya in Brazil using weekly surveillance data
```

## 五、建议论文结构

1. Introduction
2. Data sources and preprocessing
3. Descriptive epidemiological analysis
4. Baseline host-vector model
5. Climate-sensitive model extension
6. Parameter estimation and prediction validation
7. Sensitivity analysis
8. Intervention scenario analysis
9. Discussion
10. Limitations
11. Conclusion

## 六、当前最低可发表版本

最低可发表版本建议包括：

1. 2015-2025 年巴西周病例数据。
2. 至少一种气候变量，例如温度和降雨。
3. 基线模型和气候扩展模型比较。
4. 训练集/测试集预测验证。
5. 敏感性分析。
6. 3-4 种干预情景模拟。
7. 代码和数据处理流程可复现。

## 九、已确认路线

确认日期：2026-08-12

负责人已确认第一阶段路线：

1. 研究尺度：全国尺度。
2. 论文主线：真实数据预测和气候解释。
3. 理论分析：保留，并要求严谨、有数学性，参照目标论文的理论分析结构。
4. 参数估计：第一版采用非线性最小二乘拟合。
5. 模型推进顺序：先基线宿主-媒介模型，再引入气候敏感扩展。

该路线意味着第一阶段不追求一开始就完成州级空间异质性或复杂贝叶斯模型，而是优先建立全国尺度的可复现数据集、动力学拟合、短期预测验证和气候机制解释。
