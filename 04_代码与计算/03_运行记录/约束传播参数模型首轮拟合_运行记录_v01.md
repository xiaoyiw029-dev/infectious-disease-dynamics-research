# 约束传播参数模型首轮拟合运行记录 v01

记录日期：2026-08-25

## 一、运行目的

本次计算用于检验基础 SEIR-SEI 模型在全国周数据Y数据上的首轮拟合流程。为降低首轮参数相关性，传播参数采用约束形式：

$$
\beta_h=\beta_v=\beta.
$$

本次结果用于判断模型、数据、观测层和最小二乘程序是否一致，不作为最终参数结论。

## 二、拟合数据

数据文件：

```text
02_数据/01_清洗数据/baseline_fitting_cases_2023W35_2024W45.csv
```

拟合范围：

```text
2023-W35 至 2024-W45，共 63 周
```

观测量为每周全国 probable cases。模型预测量为每周从暴露宿主进入感染宿主的流量积分，并固定 $q=1$。

## 三、模型设定

宿主系统采用 SEIR，蚊媒系统采用归一化 SEI。待估参数为：

$$
\theta_c=(\beta,N_{\mathrm{eff}},E_h(0),I_h(0),i_v(0)).
$$

固定参数为：

| 参数 | 数值 | 单位 |
|---|---:|---|
| $\sigma_h$ | $1/3$ | day$^{-1}$ |
| $\gamma_h$ | $1/6$ | day$^{-1}$ |
| $\sigma_v$ | $1/11$ | day$^{-1}$ |
| $\mu_v$ | $1/14$ | day$^{-1}$ |
| $q$ | $1$ | 无量纲 |

初始条件约束为：

$$
S_h(0)=N_{\mathrm{eff}}-E_h(0)-I_h(0),\quad R_h(0)=0,\quad e_v(0)=0,\quad s_v(0)=1-i_v(0).
$$

数值计算中蚊媒仓室使用比例变量。该处理对应蚊媒总量处于平衡状态的情形，$\Lambda_v$ 不作为独立待估参数。

## 四、运行命令

脚本：

```text
04_代码与计算/00_脚本/07_fit_constrained_baseline_model.py
```

命令：

```text
python 04_代码与计算/00_脚本/07_fit_constrained_baseline_model.py --starts 100 --max-nfev 250
```

优化方式：

1. 所有待估正参数使用对数变换。
2. 使用有界最小二乘。
3. 采用 100 个多起点。
4. 目标函数为周数据Y预测值与观测值之间的平方和。

最优结果如下：

| 参数 | 估计值 | 说明 |
|---|---:|---|
| $\beta$ | 0.2256614402 | 约束传播参数，day$^{-1}$ |
| $N_{\mathrm{eff}}$ | 316,353.9680 | 有效传播与监测尺度 |
| $E_h(0)$ | 290.3009 | 初始暴露宿主数 |

## 六、诊断结果

100 个多起点中，98 个起点完成有效计算，71 个起点落在最优 SSE 的 1% 范围内。最优解在多起点中较稳定。

数值守恒检查：

| 检查项 | 结果 |
|---|---:|
| 宿主总量最大误差 | $4.44\times 10^{-16}$ |
| 蚊媒比例总和最大误差 | $9.99\times 10^{-16}$ |
| 最小状态值 | 0 |

需要注意的是，最优解存在边界贴近现象，主要表现为 $I_h(0)$ 和 $i_v(0)$ 接近下界；Jacobian 条件数约为 $4.04\times 10^7$。这说明首轮数据Y序列能够较好约束整体流行曲线和综合传播强度，但对部分初始感染状态的独立识别较弱。

## 七、拟合表现解释

约束模型能够抓住 2024 年主要流行波的上升、峰值位置和下降趋势，说明基础 SEIR-SEI 骨架与周数据Y观测层可以用于全国尺度拟合。

模型对峰后平台和尾部数据Y存在低估，提示单一常数传播参数不足以解释全部时间变化。后续应比较以下方向：

1. 放开 $\beta_h$ 与 $\beta_v$，检验双传播参数模型是否改善拟合。
2. 加入气候驱动项，使传播强度或蚊媒相关参数随温度、降水、湿度变化。
3. 对 $N_{\mathrm{eff}}$ 进行剖面分析，检查有效传播尺度的可识别范围。
4. 在固定巴西全国人口规模的条件下运行对照模型。
