# 巴西全国周数据预测研究

研究对象为巴西全国疾病X周新增数据。采用宿主 SEIR、蚊媒 SEI 动力学模型，检验气候信息是否能改善预测。当前已完成无气候基线的开发期滚动验证和峰前误差诊断，正在准备单温度项的配对实验。
