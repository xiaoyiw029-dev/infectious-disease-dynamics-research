# 传染病动力学科研文档体系

本文件夹用于集中管理传染病动力学研究中的文献、数据、模型、代码、结果、论文和协作记录。建议所有研究材料都按“来源清楚、版本可追踪、结果可复现”的原则归档。

## 目录结构

| 目录 | 用途 |
| --- | --- |
| `00_项目总览` | 研究问题、项目说明、总体索引、术语表 |
| `01_文献与综述` | 关键文献、主题综述、文献笔记、参考文献库 |
| `02_数据` | 原始数据、清洗数据、中间数据、数据字典、质量控制 |
| `03_模型与方法` | 模型设定、参数估计、敏感性分析、模型验证 |
| `04_代码与计算` | 分析脚本、notebook、环境配置、运行记录 |
| `05_结果与图表` | 主要结果、补充结果、图表源文件、导出图片 |
| `06_论文与报告` | 手稿、投稿材料、基金申请、汇报材料 |
| `07_会议与协作` | 会议纪要、合作沟通、待办事项、关键决定 |
| `08_伦理合规与数据安全` | 伦理审批、数据授权、隐私保护、脱敏说明 |
| `09_项目管理` | 时间线、任务看板、版本记录 |
| `99_归档` | 已完成、过期或冻结版本材料 |

## 基本原则

1. 原始数据只读保存，不直接修改。
2. 每次清洗、建模和分析都留下脚本、日期和输入输出说明。
3. 重要图表保留源文件、生成代码和最终导出版本。
4. 研究结论必须能追溯到数据版本、模型版本和运行记录。
5. 涉及个人、机构或地理敏感信息的数据放入合规目录，并记录授权和脱敏方式。

## 推荐文件命名

格式：

```text
YYYYMMDD_主题_内容_版本号.扩展名
```

示例：

```text
20260806_SEIR模型_参数估计_v01.md
20260806_流感监测数据_数据字典_v01.xlsx
20260806_Rt估计_主要结果_v01.csv
```

## 快速开始

1. 在 `00_项目总览/项目说明.md` 写清研究问题和范围。
2. 在 `02_数据/03_数据字典/数据字典模板.md` 建立数据字段说明。
3. 在 `03_模型与方法/模型记录模板.md` 记录模型假设、参数和公式。
4. 每次运行分析后，在 `04_代码与计算/03_运行记录` 新增一条运行记录。
5. 论文或报告中的每个核心结论，都在 `05_结果与图表` 中保留可复现来源。
