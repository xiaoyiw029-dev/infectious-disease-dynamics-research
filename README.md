## 同步范围与复现说明

本仓库保留研究文档、文献资料、模型代码、环境依赖说明、整理后的周数据、实验结果、图表和汇报材料。原始监测明细、原始气象资料、可再生成的中间数据、虚拟环境、缓存和临时编译产物不随本次同步上传。数据来源和获取说明见[数据处理流程](02_数据/README_数据处理流程.md)。

运行代码前，请检查依赖、输入路径和数据版本；部分历史脚本仍含本机路径。本次只同步及核查文件，没有重新运行全部拟合实验，也不保证在其他电脑上无需配置即可运行。原始数据处理步骤需要按来源说明另外获取原始文件。文献全文沿用原仓库资料，进一步分发时应核对各文献许可。

## 基本原则

1. 原始数据只读保存，不直接修改。
2. 每次清洗、建模和分析都留下脚本、日期和输入输出说明。
3. 重要图表保留源文件、生成代码和最终导出版本。
4. 研究结论必须能追溯到数据版本、模型版本和运行记录。
5. 涉及个人、机构或地理敏感信息的数据放入合规目录，并记录授权和脱敏方式。

## 快速开始

1. 在 `00_项目总览/项目说明.md` 写清研究问题和范围。
2. 在 `02_数据/03_数据字典/数据字典模板.md` 建立数据字段说明。
3. 在 `03_模型与方法/模型记录模板.md` 记录模型假设、参数和公式。
4. 每次运行分析后，在 `04_代码与计算/03_运行记录` 新增一条运行记录。
5. 论文或报告中的每个核心结论，都在 `05_结果与图表` 中保留可复现来源。
