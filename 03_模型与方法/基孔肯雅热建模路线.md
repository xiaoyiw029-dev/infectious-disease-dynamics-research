# 基孔肯雅热建模路线

## 一、参考论文可迁移方法

参考猴痘模型论文可迁移的是研究流程，而不是具体仓室结构。

可迁移部分：

1. 建立具有明确生物学含义的仓室模型。
2. 证明解的非负性和有界性。
3. 使用下一代矩阵法计算再生数。
4. 使用非线性最小二乘进行参数估计。
5. 将数据分为训练集和测试集进行预测验证。
6. 使用归一化前向敏感性指数做局部敏感性分析。
7. 使用 LHS-PRCC 做全局敏感性分析。
8. 通过控制变量构建干预或最优控制模型。

不能直接照搬的部分：

1. 猴痘模型中的动物宿主不能直接替代伊蚊媒介。
2. 猴痘疫苗控制变量不能直接照搬为基孔肯雅热疫苗控制。
3. 人际传播主导机制不适用于典型基孔肯雅热模型。
4. 巴西基孔肯雅热需要考虑季节性、蚊媒生态和气候滞后效应。

## 二、第一版推荐模型

人群子系统：

```text
S_h -> E_h -> I_h -> R_h
```

蚊媒子系统：

```text
S_v -> E_v -> I_v
```

建议变量：

| 符号 | 含义 |
| --- | --- |
| S_h | 易感人群 |
| E_h | 潜伏感染人群 |
| I_h | 感染并可感染蚊媒的人群 |
| R_h | 康复并具有免疫的人群 |
| S_v | 易感蚊 |
| E_v | 潜伏感染蚊 |
| I_v | 感染性蚊 |

核心参数：

| 参数 | 含义 | 来源建议 |
| --- | --- | --- |
| beta_vh | 蚊到人的有效传播率 | 拟合或文献范围 |
| beta_hv | 人到蚊的有效传播率 | 拟合或文献范围 |
| sigma_h | 人潜伏期倒数 | 文献 |
| gamma_h | 人感染期倒数 | 文献或拟合 |
| sigma_v | 蚊外潜伏期倒数 | 文献，后续可设为温度函数 |
| mu_v | 蚊死亡率 | 文献，后续可设为气候函数 |
| Lambda_v | 蚊补充率 | 拟合或季节函数 |

## 三、观测方程

病例数据不是直接等于 I_h。

建议使用新增病例观测：

$$
\mathrm{reported\_cases\_week}(t)
=\rho\int_{\text{week }t}\sigma_h E_h(\tau)\,d\tau
$$

其中 rho 是报告率或缩放因子。

若只做拟合入门版，也可以把模型产生的周新增感染数与官方周病例直接拟合，但必须在论文中说明这是观测近似。

## 四、参数估计策略

### 入门版

目标函数：

$$
\min \sum_t
\left[
\mathrm{observed\_cases}(t)
-\mathrm{simulated\_cases}(t)
\right]^2
$$

优点：

- 实现简单。
- 与参考猴痘论文一致。
- 适合本科科研训练的第一版。

局限：

- 病例数据通常过度离散。
- 高峰期误差权重过大。
- 不直接表达计数数据不确定性。

### 进阶版

使用泊松或负二项似然：

$$
\mathrm{cases}(t)\sim
\mathrm{NegativeBinomial}
\left(
\mathrm{mean}=\mathrm{simulated\_cases}(t),
\mathrm{dispersion}=k
\right)
$$

优点：

- 更符合病例计数数据。
- 可以表达过度离散。
- 适合更严谨论文。

建议：

- 第一版先做最小二乘。
- 若拟合残差明显随病例规模增大，再升级负二项似然。

## 五、训练集与测试集

参考猴痘论文的做法是将前段数据作为训练集，后段数据作为测试集。

本项目可选：

1. 固定切分：例如 2015-2023 训练，2024-2025 测试。
2. 滚动预测：用过去若干周拟合，预测未来 4-8 周。
3. 爆发年验证：用非爆发年训练，检验爆发年的预测能力。

建议先使用固定切分，后续再做滚动预测。

## 六、气候因子引入策略

建议从简单到复杂：

### 方案 A：传播率线性气候修正

$$
\beta_{vh}(t)=\beta_0
\max\left[
0,\,
1+a_TT_{\mathrm{std}}(t-\mathrm{lag})
+a_PP_{\mathrm{std}}(t-\mathrm{lag})
\right]
$$

### 方案 B：指数气候修正

$$
\beta_{vh}(t)=\beta_0
\exp\left[
a_TT_{\mathrm{std}}(t-\mathrm{lag})
+a_PP_{\mathrm{std}}(t-\mathrm{lag})
\right]
$$

### 方案 C：蚊媒参数气候驱动

$$
\begin{aligned}
\mu_v(t) &= f_{\mathrm{temperature}}(T),\\
\sigma_v(t) &= g_{\mathrm{temperature}}(T),\\
\Lambda_v(t) &= h_{\mathrm{rainfall}}(P).
\end{aligned}
$$

建议从方案 A 或 B 开始。方案 C 生物学解释更强，但参数更多，拟合更难。

## 七、敏感性分析指标

建议至少分析三个输出：

1. R0 或 Rt。
2. 疫情峰值。
3. 累计病例数。

局部敏感性：

$$
S_x=\frac{x}{Q}\frac{\partial Q}{\partial x}
$$

全局敏感性：

- 设定每个参数的合理范围。
- LHS 抽样。
- 对每组参数运行模型。
- 计算 PRCC。

## 八、干预模拟

建议优先做情景模拟，再考虑最优控制。

| 干预 | 模型表达 | 公共卫生含义 |
| --- | --- | --- |
| 灭蚊 | 提高 mu_v 或降低 Lambda_v | 杀虫剂、清除孳生地 |
| 减少叮咬 | 降低 beta_vh 和 beta_hv | 驱蚊剂、纱窗、个人防护 |
| 病例管理 | 提高 gamma_h 或降低有效感染期 | 早诊断、休息隔离、避免被蚊叮咬 |
| 环境治理 | 降低降雨对蚊媒补充率的影响 | 清理积水、垃圾处理 |

## 九、当前推荐的最小可行模型

为了保证研究能真实落地，建议第一版只做：

1. 全国或 3-5 个重点州周病例曲线。
2. SEIR-蚊媒模型。
3. 最小二乘拟合。
4. 训练集/测试集预测。
5. 局部敏感性分析。
6. 三种干预情景模拟。

气候敏感模型和最优控制作为第二版扩展。
