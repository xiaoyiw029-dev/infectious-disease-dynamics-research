# 基础模型符号说明 v01

更新时间：2026-08-15

对应模型图：`基础模型图_SEIR_SEI_v04_清晰标注版.svg`

## 状态变量

| 符号 | 含义 |
|---|---|
| `S_h` | 易感宿主，尚未感染且可被感染蚊媒感染的人群 |
| `E_h` | 暴露宿主，已经感染但尚未具有传染性的人群 |
| `I_h` | 感染宿主，具有传染性并可感染易感蚊媒的人群 |
| `R_h` | 康复宿主，感染恢复后获得免疫的人群 |
| `S_v` | 易感蚊媒，尚未感染但可通过叮咬感染宿主而感染 |
| `E_v` | 暴露蚊媒，已经感染但尚未具有传播能力的蚊媒 |
| `I_v` | 感染蚊媒，具有传播能力并可感染易感宿主 |

## 参数

| 符号 | 含义 |
|---|---|
| `lambda_h` | 宿主感染力，表示易感宿主进入暴露宿主阶段的速率 |
| `sigma_h` | 宿主潜伏期结束速率，表示暴露宿主进入感染宿主阶段的速率 |
| `gamma_h` | 宿主恢复率，表示感染宿主进入康复宿主阶段的速率 |
| `lambda_v` | 蚊媒感染力，表示易感蚊媒进入暴露蚊媒阶段的速率 |
| `sigma_v` | 蚊媒外潜伏期结束速率，表示暴露蚊媒进入感染蚊媒阶段的速率 |
| `Lambda_v` | 易感蚊媒补充率，表示新成蚊进入易感蚊媒仓室的速率 |
| `mu_v` | 蚊媒死亡率，表示蚊媒从各蚊媒仓室自然死亡移出的速率 |
| `beta_h` | 蚊媒到宿主的传播参数，描述感染蚊媒对易感宿主感染风险的贡献 |
| `beta_v` | 宿主到蚊媒的传播参数，描述感染宿主对易感蚊媒感染风险的贡献 |
