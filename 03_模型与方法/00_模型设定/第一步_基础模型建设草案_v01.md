# 第一步：基础传播模型建设草案 v01

更新时间：2026-08-15

本文档用于正式确立论文第一层模型：不含气候因子、不含空间分区、不含干预措施的巴西基孔肯雅热基础人-蚊传播模型。该模型作为后续气候扩展、参数拟合、预测验证和理论分析的共同起点。

已确认决策：

- 微分方程时间单位采用“天”；
- 感染力采用比例感染形式，即宿主感染力使用感染蚊媒比例 `I_v/N_v`，蚊媒感染力使用感染宿主比例 `I_h/N_h`。

## 1. 第一步的目标

第一步只解决一个问题：

> 在没有气候驱动和复杂扩展之前，基孔肯雅热如何通过人群和蚊媒完成基本传播？

因此，本阶段不讨论温度、降雨、区域差异、机器学习预测、控制措施和完整幼蚊生态。它们都放在后续扩展模型中处理。

## 2. 基础模型选择

采用人群 `SEIR` 与蚊媒 `SEI` 的耦合模型：

```text
Human:    S_h -> E_h -> I_h -> R_h
Mosquito: S_v -> E_v -> I_v
```

其中：

- 人群存在潜伏期，所以使用 `E_h`。
- 蚊媒存在外潜伏期，所以使用 `E_v`。
- 人感染恢复后获得长期免疫，所以进入 `R_h`。
- 蚊媒感染后不恢复，直到死亡。
- 第一版不单独设置无症状感染仓室，而是通过报告率或观测比例吸收监测数据与真实感染之间的差异。

## 3. 状态变量

| 符号 | 含义 |
|---|---|
| `S_h(t)` | 易感人群 |
| `E_h(t)` | 已感染但尚未具有传染性的人群 |
| `I_h(t)` | 具有传染性的人群 |
| `R_h(t)` | 恢复并获得免疫的人群 |
| `S_v(t)` | 易感蚊媒 |
| `E_v(t)` | 已感染但尚未具有传染性的蚊媒 |
| `I_v(t)` | 具有传染性的蚊媒 |

人群总量：

$$
N_h(t)=S_h(t)+E_h(t)+I_h(t)+R_h(t)
$$

蚊媒总量：

$$
N_v(t)=S_v(t)+E_v(t)+I_v(t)
$$

## 4. 核心参数

| 参数 | 含义 |
|---|---|
| `beta_h` | 感染蚊媒导致人群感染的有效传播率 |
| `beta_v` | 感染人群导致蚊媒感染的有效传播率 |
| `sigma_h` | 人群潜伏期结束并进入感染期的速率 |
| `gamma_h` | 感染人群恢复速率 |
| `sigma_v` | 蚊媒外潜伏期结束并进入感染期的速率 |
| `mu_v` | 蚊媒死亡率 |
| `Lambda_v` | 蚊媒补充率 |
| `q` | 报告率或观测比例 |

如果研究期较短，第一版可以暂时忽略人群自然出生死亡；若研究期较长，可在后续版本加入人群出生死亡项。

## 5. 传播力设定

人群感染力：

$$
\lambda_h(t)=\beta_h\frac{I_v(t)}{N_v(t)}
$$

蚊媒感染力：

$$
\lambda_v(t)=\beta_v\frac{I_h(t)}{N_h(t)}
$$

这里采用比例感染形式。`I_v(t)/N_v(t)` 表示感染蚊媒比例，`I_h(t)/N_h(t)` 表示感染宿主比例，因此 `lambda_h(t)` 和 `lambda_v(t)` 均可解释为单位时间内的感染力。

## 6. 基础方程

第一版基础模型可写为：

$$
\begin{aligned}
\frac{dS_h}{dt} &= -\lambda_h(t)S_h,\\
\frac{dE_h}{dt} &= \lambda_h(t)S_h-\sigma_h E_h,\\
\frac{dI_h}{dt} &= \sigma_h E_h-\gamma_h I_h,\\
\frac{dR_h}{dt} &= \gamma_h I_h,\\
\frac{dS_v}{dt} &= \Lambda_v-\lambda_v(t)S_v-\mu_v S_v,\\
\frac{dE_v}{dt} &= \lambda_v(t)S_v-\sigma_v E_v-\mu_v E_v,\\
\frac{dI_v}{dt} &= \sigma_v E_v-\mu_v I_v.
\end{aligned}
$$

其中：

$$
\lambda_h(t)=\beta_h\frac{I_v(t)}{N_v(t)},\qquad
\lambda_v(t)=\beta_v\frac{I_h(t)}{N_h(t)}.
$$

## 7. 周病例观测层

真实监测数据通常是每周报告病例，不应直接等同于 `I_h(t)`。

建议将第 `k` 周模型预测报告病例定义为：

$$
C_k=q\int_{\text{week }k}\sigma_h E_h(t)\,dt
$$

离散表达为：

$$
C_k=q\sum_{d\in \text{week }k}\sigma_h E_h(d)
$$

含义：

- `sigma_h * E_h(t)` 是潜伏者进入感染期的流量，可近似代表新发病例流。
- `q` 表示报告率、确诊比例或监测可见比例。
- 这样可以避免把“当前感染者存量”误当成“每周新增病例”。

## 8. 第一版暂不纳入的内容

| 暂不纳入内容 | 暂缓理由 | 后续处理 |
|---|---|---|
| 无症状仓室 `A_h` | 周报告病例通常不足以同时识别无症状比例和传播能力 | 作为扩展模型或敏感性分析 |
| 卵、幼虫、蛹等蚊媒生态阶段 | 参数较多，全国尺度识别难度高 | 后续用气候驱动的蚊媒补充率或承载量近似 |
| 温度和降雨 | 第一版先建立可分析的自治模型 | 第二步作为时间变参数进入 |
| 空间分区 | 第一版先确认全国聚合模型 | 后续做五大区或州级稳健性 |
| 干预措施 | 不是基础传播机制 | 后续情景模拟 |
| 直接人传人 | CHIKV 主要经蚊媒传播 | 第一版忽略 |

## 9. 这一模型能支持的后续工作

该基础模型确定后，可以继续开展：

1. 证明解的非负性和有界性。
2. 求疾病消除平衡。
3. 用下一代矩阵法推导基本再生数 `R0`。
4. 分析疾病消除平衡的局部稳定性。
5. 用最小二乘法拟合巴西全国周病例。
6. 在 `beta_h(t)`, `beta_v(t)`, `mu_v(t)` 或 `Lambda_v(t)` 中加入气候因子。
7. 与 SARIMA、Richards 曲线或机器学习预测结果进行对比。

## 10. 已确认事项

当前基础模型已确认以下事项：

| 编号 | 事项 | 当前状态 |
|---|---|---|
| Q1 | 人群是否采用 `S_h, E_h, I_h, R_h` | 是 |
| Q2 | 蚊媒是否采用 `S_v, E_v, I_v` | 是 |
| Q3 | 第一版是否不单独设置无症状仓室 | 是 |
| Q4 | 周病例是否用 `q * integral sigma_h E_h(t) dt` 表示 | 是 |
| Q5 | 微分方程时间单位是否采用“天” | 已确认：是 |
| Q6 | 感染力是否采用比例感染形式 `I_v/N_v` 与 `I_h/N_h` | 已确认：是 |

只要这四点确认，下一步即可正式写“模型假设”和“模型方程”两节，并开始准备 `R0` 推导。
