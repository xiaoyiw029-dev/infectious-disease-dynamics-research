## 1. 建模时间尺度

基础模型采用连续时间确定性微分方程，时间变量记为 `t`，单位为“天”。

后续真实监测数据若为周病例，则通过观测层将每日模型流量汇总为周尺度预测病例。

## 2. 状态变量

宿主人群：

```text
S_h(t): 易感宿主
E_h(t): 暴露宿主
I_h(t): 感染宿主
R_h(t): 康复宿主
```

蚊媒种群：

```text
S_v(t): 易感蚊媒
E_v(t): 暴露蚊媒
I_v(t): 感染蚊媒
```

宿主总量：

```text
N_h(t) = S_h(t) + E_h(t) + I_h(t) + R_h(t)
```

蚊媒总量：

```text
N_v(t) = S_v(t) + E_v(t) + I_v(t)
```

第一版基础模型暂不显式加入宿主自然出生和自然死亡，因此：

```text
dN_h(t)/dt = 0
```

蚊媒种群存在补充和自然死亡，因此：

```text
dN_v(t)/dt = Λ_v - μ_v N_v(t)
```

## 3. 感染力定义

根据已确认的方案 B，基础模型采用比例感染形式。

宿主感染力：

```text
λ_h(t) = β_h I_v(t) / N_v(t)
```

蚊媒感染力：

```text
λ_v(t) = β_v I_h(t) / N_h(t)
```

其中：

- `I_v(t)/N_v(t)` 表示感染蚊媒比例；
- `I_h(t)/N_h(t)` 表示感染宿主比例；
- `β_h` 表示蚊媒到宿主的传播参数；
- `β_v` 表示宿主到蚊媒的传播参数。

## 4. 基础微分方程系统

宿主方程：

```text
dS_h/dt = - λ_h(t) S_h

dE_h/dt =   λ_h(t) S_h - σ_h E_h

dI_h/dt =   σ_h E_h - γ_h I_h

dR_h/dt =   γ_h I_h
```

蚊媒方程：

```text
dS_v/dt = Λ_v - λ_v(t) S_v - μ_v S_v

dE_v/dt =   λ_v(t) S_v - σ_v E_v - μ_v E_v

dI_v/dt =   σ_v E_v - μ_v I_v
```

完整系统可写为：

```text
dS_h/dt = - β_h [I_v(t) / N_v(t)] S_h

dE_h/dt =   β_h [I_v(t) / N_v(t)] S_h - σ_h E_h

dI_h/dt =   σ_h E_h - γ_h I_h

dR_h/dt =   γ_h I_h

dS_v/dt = Λ_v - β_v [I_h(t) / N_h(t)] S_v - μ_v S_v

dE_v/dt =   β_v [I_h(t) / N_h(t)] S_v - σ_v E_v - μ_v E_v

dI_v/dt =   σ_v E_v - μ_v I_v
```

## 5. 方程与模型图的对应关系

| 模型图箭头 | 方程中的转移流量 | 含义 |
|---|---|---|
| `S_h -> E_h` | `λ_h(t) S_h` | 易感宿主被感染蚊媒感染后进入暴露期 |
| `E_h -> I_h` | `σ_h E_h` | 暴露宿主潜伏期结束后进入感染期 |
| `I_h -> R_h` | `γ_h I_h` | 感染宿主恢复并进入康复期 |
| `S_v -> E_v` | `λ_v(t) S_v` | 易感蚊媒叮咬感染宿主后进入暴露期 |
| `E_v -> I_v` | `σ_v E_v` | 暴露蚊媒外潜伏期结束后进入感染蚊媒阶段 |
| `Λ_v -> S_v` | `Λ_v` | 新成蚊补充进入易感蚊媒仓室 |
| `S_v, E_v, I_v -> 移出` | `μ_v S_v`, `μ_v E_v`, `μ_v I_v` | 蚊媒自然死亡 |

## 6. 周病例观测方程

模型中的 `I_h(t)` 表示某一时刻的感染宿主存量，不直接等于每周报告病例。

第 `k` 周模型预测报告病例定义为：

```text
C_k = q ∫_{week k} σ_h E_h(t) dt
```

其中：

- `C_k` 表示第 `k` 周模型预测报告病例数；
- `q` 表示报告率或监测可见比例；
- `σ_h E_h(t)` 表示单位时间内从暴露期进入感染期的宿主流量；
- 积分区间为第 `k` 周对应的 7 天。

若采用日步长数值计算，可近似为：

```text
C_k ≈ q Σ_{d in week k} σ_h E_h(d) Δt
```

当 `Δt = 1 day` 时：

```text
C_k ≈ q Σ_{d in week k} σ_h E_h(d)
```

## 7. 当前方程系统的边界条件要求

为保证模型具有生物学意义，初始条件应满足：

```text
S_h(0) >= 0, E_h(0) >= 0, I_h(0) >= 0, R_h(0) >= 0
S_v(0) >= 0, E_v(0) >= 0, I_v(0) >= 0
N_h(0) > 0, N_v(0) > 0
```

参数应满足：

```text
β_h >= 0, β_v >= 0
σ_h > 0, γ_h > 0, σ_v > 0
Λ_v >= 0, μ_v > 0
0 <= q <= 1
```

## 8. 需要后续确认但不影响当前方程的问题

当前方程已经可以进入疾病消除平衡和 `R0` 推导。后续在参数估计阶段还需要确认：

1. 是否令蚊媒初始总量处于平衡状态，即 `N_v(0) = Λ_v / μ_v`；
2. `Λ_v` 是固定给定、由蚊媒平衡关系确定，还是作为待估计参数；
3. `q` 是作为待估计参数，还是给定多个情景值做敏感性分析；
4. 初始感染宿主 `I_h(0)` 和初始感染蚊媒 `I_v(0)` 如何设定。

这些问题会影响拟合策略，但不改变当前基础方程结构。
