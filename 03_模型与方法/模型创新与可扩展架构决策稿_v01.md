# 基孔肯雅热模型创新与可扩展架构决策稿 v0.1

更新时间：2026-08-13

## 1. 核心判断

采用经典的人群 `SEIR` - 蚊媒 `SEI` 传播骨架，不等于抄袭，也不会天然妨碍发表。该结构表达的是公认的宿主-媒介传播机制，属于领域公共框架。规范做法是引用 C01、C03-C06，并说明本研究是在经典框架上的扩展。

真正的风险是：

1. 照搬某篇论文的假设、符号、方程排列、模型图、参数表、证明文字和情景设置；
2. 只改变量名或多加一个仓室，却没有新的科学问题、数据证据或可检验结论；
3. 未完成系统检索便声称“首次”；
4. 添加无法由数据识别的参数，使模型复杂但结论不可靠。

创新不应以仓室数量衡量，而应体现在科学问题、机制表达、观测过程、预测验证与区域稳健性上。

## 2. 为什么不能照搬猴痘论文的疫苗创新

猴痘参考文献的贡献，是在其研究背景下把疫苗保护效力纳入特定 Mpox 模型。基孔肯雅热的现状已经不同：巴西 Anvisa 于 2025 年批准基孔肯雅疫苗；2025-2026 年已出现疫苗反应性接种、全球疫苗收益、巴西年龄定向免疫和两类疫苗成本效果模型。

因此，仅增加 `V_h` 仓室或疫苗效力参数，不能稳妥地声称“首次”，也不足以单独支撑本项目的创新。疫苗仍可作为后续模块，但需研究更具体的问题，例如气候异常与接种窗口、地区定向策略、防感染与防发病效力差异、部署延迟与报告延迟、疫苗和媒介控制组合策略。

## 3. 推荐的模块化架构

### 3.1 模块 A：自治理论基线

```text
人群：S_h -> E_h -> I_h -> R_h
蚊媒：S_v -> E_v -> I_v
```

用途：证明正性、有界性、无病平衡、R0 和稳定性。该模块保持常系数，承担数学严谨性，也是所有扩展的共同基准。

### 3.2 模块 B：病例观测层

真实新感染流：

```text
incidence_true(t) = sigma_h E_h(t)
```

第 k 周期望报告病例：

```text
mu_k = q * integral_week_k sigma_h E_h(t) dt
```

`q` 是综合观测比例，包含有症状、就医、诊断和报告概率。第一版不同时拆分这些比例，因为仅凭周报告病例通常只能识别其乘积。

第一阶段可用非线性最小二乘；稳健性分析建议增加负二项观测模型或加权最小二乘，以处理过度离散。

### 3.3 模块 C：气候机制层

不建议让气候同时自由修改所有蚊媒参数。推荐“文献固定响应形状 + 数据估计少量尺度参数”：

```text
a(t)       = a_T(T(t))
sigma_v(t) = sigma_T(T(t))
mu_v(t)    = mu_T(T(t))
m(t)       = m0 * exp(alpha_P * P_std(t-lag_P))
```

- 温度热响应形状优先采用 C07/C08 的实验整合函数；
- 温度作用于叮咬、蚊媒死亡和外潜伏期；
- 降雨优先作用于有效蚊人比或蚊媒丰度尺度 `m(t)`；
- 主要估计 `m0`、`alpha_P`、候选滞后和少量区域尺度参数。

必须比较：

```text
M0：常系数基线
M1：纯季节项
M2：温度机制
M3：温度机制 + 降雨滞后
```

只有 M2/M3 在样本外预测和残差诊断上优于 M0/M1，才能说明气候信息产生了实际贡献。

### 3.4 模块 D：区域聚合层

巴西全国病例是地区异步流行的总和。更合理的最终形式是：

```text
C_Brazil(k) = sum_r C_r(k)
```

每个地区具有自己的气候、初值、蚊媒尺度和观测比例，同时共享疾病自然史参数和热响应函数。若第一阶段资源有限，可先完成全国模型，但五大区域分析应作为必须完成的稳健性检查。

### 3.5 模块 E：干预与疫苗层

干预通过参数接口接入，而不改写基础传播逻辑：

- 媒介控制：降低 `m(t)` 或提高 `mu_v(t)`；
- 个人防护：降低叮咬率或传播概率；
- 疫苗：需要时增加 `V_h`，区分防感染与防发病效力；
- 反应性接种：加入部署延迟、覆盖率和接种速度。

这种分层设计使后续增加疫苗或联合干预时，不必推翻理论、气候和观测模块。

## 4. 无症状仓室决策

当前建议：第一版不把 `I_h` 拆分为 `I_s` 与 `I_a`，但在观测层保留综合比例 `q`。

理由：

1. C03、C06 等已有无症状仓室，单纯加入不构成创新；
2. 周报告病例通常无法同时识别无症状比例、相对传染性、恢复率和报告率；
3. 若两类感染具有相同传染性和恢复率，数学上可以合并，拆分会产生冗余参数；
4. 巴西局地血清学结果差异较大，不宜将某一地区比例直接固定为全国值。

满足以下条件之一时再加入：

- 获得可约束真实感染总量的巴西血清学数据；
- 有可靠证据支持有症状与无症状感染的传染性或感染期不同；
- 研究问题直接针对症状负担或发现率；
- 可辨识性分析支持新增参数可稳定估计。

## 5. 候选创新组合及检索边界

候选主线：**气候机制 + 观测层 + 样本外预测 + 区域稳健性**。

截至 2026-08-13 的补充检索表明，上述每个单项和若干组合均已有研究，不能把这一宽泛组合直接称为“首次”。可能成立的增量创新需收窄为：在统一宿主-媒介动力学框架中，用生物学约束的气候响应和显式观测层，检验其相对纯季节及统计基线的跨年份、跨区域预测增益。创新性最终由模型消融和样本外结果证明，而不是由研究设计文字预先保证。

现阶段可作为研究目标表述为：

> 评估具有严格阈值理论和显式病例观测过程的气候驱动宿主-媒介模型，是否能够改善巴西基孔肯雅热周病例的跨年份样本外预测，并检验其气候响应在五大区域间的可迁移性与稳健性。

不建议作为主要创新：仅增加无症状仓室、仅增加疫苗仓室、仅把温度降雨线性加入传播率、仅做无真实数据的最优控制、通过大量仓室制造复杂度。

## 6. 避免抄袭的具体做法

1. 建立模型谱系表，说明分别继承和修改 C01、C04、C05、C06 的哪些思想；
2. 根据本研究假设独立绘图、定义符号、写方程并推导 R0；
3. 参数逐项追溯原始来源，不整表复制；
4. 标准理论方法也注明来源；
5. 不默认使用“首次”，优先表述“整合”“在巴西长期周尺度上评估”；
6. 对每个扩展做消融比较，证明它改善预测、残差或科学解释。

## 7. 新增仓室的门槛

每增加一个仓室或机制，必须回答：

1. 对应什么生物过程和科学问题？
2. 有什么文献或数据证据？
3. 新增哪些参数？
4. 参数能否由现有数据识别？
5. 删除后预测或结论是否明显变差？
6. 是否改变 R0 和稳定性证明？
7. 是否与报告率、初始易感比例或气候系数混淆？

关键问题无答案时，该模块只作为扩展候选，不进入主模型。

## 8. 当前推荐决策

1. 保留 `SEIR-SEI` 作为共同骨架；
2. 第一版不拆无症状仓室；
3. 优先确立显式病例观测层；
4. 气候采用实验热响应函数和少量待估尺度参数；
5. 全国结果至少增加五区稳健性分析，理想方案为区域模型汇总全国；
6. 疫苗暂不作为首篇论文核心创新，保留为后续政策模块。
