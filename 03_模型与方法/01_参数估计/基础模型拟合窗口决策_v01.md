# 基础模型拟合窗口决策_v01

记录日期：2026-08-25

## 一、拟合窗口

基础模型主拟合窗口确定为：

```text
2023-W35 至 2024-W45
```

对应日期范围：

```text
2023-08-27 至 2024-11-09
```

窗口长度：

```text
63 周
```

该窗口覆盖 2024 年主要流行波的上升段、峰值段、下降段和后期低水平尾部。

## 二、输入数据

拟合数据文件：

```text
02_数据/01_清洗数据/baseline_fitting_cases_2023W35_2024W45.csv
```

来源数据：

```text
02_数据/01_清洗数据/brazil_weekly_chikungunya_cases.csv
```

数据Y口径：

```text
probable cases = 所有通知记录中排除 CLASSI_FIN=5 的 discarded 数据Y
```

主数据Y列：

```text
cases
```

其中 `cases` 与 `probable_cases` 相同。

## 三、时间变量

拟合数据中保留两个时间变量：

| 字段 | 含义 | 单位 |
|---|---|---|
| `t_week` | 从拟合窗口起点开始的周索引 | 周 |
| `t_day` | 从拟合窗口起点开始的日索引 | 天 |

由于基础动力学模型的时间单位已确定为天，后续参数估计应优先使用：

```text
t_day
```

## 五、选择理由

该窗口作为基础模型主拟合期的理由如下：

1. 窗口长度为 63 周，适合常参数基础动力学模型刻画单次主要流行波。
2. 窗口包含低水平传播、快速上升、峰值、下降和尾部阶段。
3. 该窗口覆盖当前可用监测序列中规模最大且完整的流行波。
4. 该窗口不包含 2025 年后续新一轮波动，避免把多个传播阶段混入同一基础模型。
5. 该窗口处于数据Y分类相对稳定的阶段，优于 2015-2016 年早期数据。

## 六、注意事项

1. 该窗口用于基础模型主拟合，不代表长期气候扩展模型的最终拟合期。
2. 2024 年并非最新年份，应表述为“可用监测序列中规模最大且完整的流行波”，不应表述为“最新流行波”。
3. 若基础模型拟合结果对窗口边界敏感，应设置窗口敏感性分析。
4. 后续可考虑以 `2024-W01 至 2024-W40` 作为较短窗口敏感性分析。
5. 若引入气候扩展模型，可将拟合期扩展至 2022-2025 年，并保留 2026 年作为外推验证候选。

英文草稿：

```text
For the baseline host-vector model, the main fitting window was selected from epidemiological week 2023-W35 to 2024-W45. This interval covers the rise, peak, decline, and post-peak tail of the largest complete epidemic wave in the available Brazilian chikungunya surveillance series. Weekly probable cases, defined as notified records excluding discarded cases, were used as the infection-case series for nonlinear least-squares fitting.

```

## 九、当前用途（2026-10-15更新）

本窗口已完成全段拟合和开发期滚动验证。正式模型输出为周新增流量，采用训练周预测值与观测值的残差平方和；不以周末感染存量作为周新增观测。参数及边界见[参数估计设置](基础模型参数估计准备_v01.md)。

该窗口反复参与模型探索，不能再作为独立测试集。本文保留选窗依据；下一轮工作以[单温度扩展方案](单温度机制扩展_方案_v01.md)为准。
