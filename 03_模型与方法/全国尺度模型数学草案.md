# 全国尺度模型数学草案

确认路线：全国尺度；主打真实数据预测和气候解释；理论分析保留；第一版采用非线性最小二乘拟合。

## 一、模型目的

本模型用于刻画巴西全国尺度基孔肯雅病毒在人群和蚊媒之间的传播过程，并进一步分析气候因子对传播强度季节波动的影响。

模型分为两个版本：

1. 基线宿主-媒介模型：传播参数为常数。
2. 气候敏感扩展模型：传播参数或蚊媒参数随温度、降雨等气候变量变化。

## 二、变量定义

### 人群子系统

| 变量 | 含义 |
| --- | --- |
| S_h(t) | t 时刻易感人群数量 |
| E_h(t) | t 时刻潜伏感染人群数量 |
| I_h(t) | t 时刻感染并可感染蚊媒的人群数量 |
| R_h(t) | t 时刻康复或移除人群数量 |

总人群：

```text
N_h(t) = S_h(t) + E_h(t) + I_h(t) + R_h(t)
```

第一版可近似认为全国人口在研究时段内缓慢变化或常数：

```text
N_h(t) = N_h
```

### 蚊媒子系统

| 变量 | 含义 |
| --- | --- |
| S_v(t) | t 时刻易感雌性成蚊数量 |
| E_v(t) | t 时刻潜伏感染蚊数量 |
| I_v(t) | t 时刻感染性蚊数量 |

总蚊媒：

```text
N_v(t) = S_v(t) + E_v(t) + I_v(t)
```

第一版可将蚊媒种群规模设为常数或由出生死亡项维持。

## 三、基线模型方程

建议第一版模型为：

```text
dS_h/dt = mu_h N_h - lambda_h(t) S_h - mu_h S_h

dE_h/dt = lambda_h(t) S_h - (sigma_h + mu_h) E_h

dI_h/dt = sigma_h E_h - (gamma_h + mu_h) I_h

dR_h/dt = gamma_h I_h - mu_h R_h

dS_v/dt = Lambda_v - lambda_v(t) S_v - mu_v S_v

dE_v/dt = lambda_v(t) S_v - (sigma_v + mu_v) E_v

dI_v/dt = sigma_v E_v - mu_v I_v
```

其中感染力定义为：

```text
lambda_h(t) = beta_vh * I_v / N_h

lambda_v(t) = beta_hv * I_h / N_h
```

说明：

- beta_vh 表示感染性蚊对人的有效传播率。
- beta_hv 表示感染人群对蚊的有效传播率。
- sigma_h 是人潜伏期倒数。
- gamma_h 是人感染期倒数。
- sigma_v 是蚊外潜伏期倒数。
- mu_v 是蚊死亡率。
- Lambda_v 是蚊补充率。

## 四、参数定义

| 参数 | 含义 | 第一版处理 |
| --- | --- | --- |
| mu_h | 人自然死亡率 | 文献或人口寿命固定 |
| beta_vh | 蚊到人有效传播率 | 拟合 |
| beta_hv | 人到蚊有效传播率 | 拟合或与 beta_vh 合并 |
| sigma_h | 人潜伏期倒数 | 文献固定 |
| gamma_h | 人感染期倒数 | 文献固定或拟合 |
| Lambda_v | 蚊补充率 | 固定或拟合 |
| mu_v | 蚊死亡率 | 文献固定 |
| sigma_v | 蚊外潜伏期倒数 | 文献固定 |
| rho | 报告率或观测缩放系数 | 拟合 |

为降低参数不可辨识风险，第一版建议：

- 固定 sigma_h、gamma_h、sigma_v、mu_v。
- 拟合 beta_vh、beta_hv、rho 和少量初值参数。
- 若 beta_vh 和 beta_hv 难以同时识别，可使用组合参数或固定其中一个比例关系。

## 五、观测方程

官方病例数据是按周报告的新增病例，不应直接等同于 I_h(t)。

推荐观测方程：

```text
C_model(k) = rho * integral_{week k} sigma_h E_h(t) dt
```

其中：

- C_model(k) 表示模型预测的第 k 周报告病例数。
- sigma_h E_h(t) 表示从潜伏期进入感染期的新发感染流。
- rho 表示报告率、检测率和尺度误差的综合因子。

实际数值计算中，可以在 ODE 中加入累计发病变量 A(t)：

```text
dA/dt = sigma_h E_h
```

第 k 周模型新增病例为：

```text
C_model(k) = rho * [A(t_k) - A(t_{k-1})]
```

## 六、非线性最小二乘拟合

第一版目标函数：

```text
L(theta) = sum_{k in training} [C_obs(k) - C_model(k; theta)]^2
```

可选加权版本：

```text
L_w(theta) = sum_{k in training} w_k [C_obs(k) - C_model(k; theta)]^2
```

其中：

```text
w_k = 1 / max(C_obs(k), 1)
```

或使用平方根变换：

```text
L_s(theta) = sum_{k in training} [sqrt(C_obs(k) + 1) - sqrt(C_model(k; theta) + 1)]^2
```

第一版主分析建议使用普通最小二乘；加权或变换作为敏感性分析。

## 七、非负性证明框架

若初始值满足：

```text
S_h(0), E_h(0), I_h(0), R_h(0), S_v(0), E_v(0), I_v(0) >= 0
```

则模型解在 t > 0 时保持非负。

证明思路：

在每个坐标平面上检查向量场方向：

- 当 S_h = 0 时，dS_h/dt = mu_h N_h >= 0。
- 当 E_h = 0 时，dE_h/dt = lambda_h S_h >= 0。
- 当 I_h = 0 时，dI_h/dt = sigma_h E_h >= 0。
- 当 R_h = 0 时，dR_h/dt = gamma_h I_h >= 0。
- 当 S_v = 0 时，dS_v/dt = Lambda_v >= 0。
- 当 E_v = 0 时，dE_v/dt = lambda_v S_v >= 0。
- 当 I_v = 0 时，dI_v/dt = sigma_v E_v >= 0。

因此非负正锥是不变集。

## 八、有界性证明框架

人群总量：

```text
dN_h/dt = mu_h N_h - mu_h N_h = 0
```

因此：

```text
N_h(t) = N_h(0)
```

若采用常数人口输入和自然死亡，则人群总量有界。

蚊媒总量：

```text
dN_v/dt = Lambda_v - mu_v N_v
```

因此：

```text
N_v(t) <= max{N_v(0), Lambda_v / mu_v}
```

可行域：

```text
Omega = {0 <= N_h <= N_h0, 0 <= N_v <= Lambda_v / mu_v}
```

为正不变且有界。

## 九、无病平衡点

无病状态：

```text
E_h = I_h = E_v = I_v = 0
```

无病平衡点可写为：

```text
E0 = (S_h^0, 0, 0, R_h^0, S_v^0, 0, 0)
```

若假设研究初始时全部人群易感且无感染：

```text
S_h^0 = N_h
R_h^0 = 0
S_v^0 = Lambda_v / mu_v
```

则：

```text
E0 = (N_h, 0, 0, 0, Lambda_v / mu_v, 0, 0)
```

## 十、基本再生数 R0 草案

感染相关变量取：

```text
x = (E_h, I_h, E_v, I_v)
```

新感染项：

```text
F_1 = beta_vh * S_h^0 * I_v / N_h
F_2 = 0
F_3 = beta_hv * S_v^0 * I_h / N_h
F_4 = 0
```

转移项：

```text
V_1 = (sigma_h + mu_h) E_h
V_2 = (gamma_h + mu_h) I_h - sigma_h E_h
V_3 = (sigma_v + mu_v) E_v
V_4 = mu_v I_v - sigma_v E_v
```

通过下一代矩阵：

```text
K = F V^{-1}
```

基本再生数为 K 的谱半径：

```text
R0 = rho(K)
```

对于该宿主-媒介循环，常见表达形式可整理为：

```text
R0 = sqrt(
  beta_vh * beta_hv
  * (S_h^0 / N_h)
  * (S_v^0 / N_h)
  * sigma_h / (sigma_h + mu_h)
  * 1 / (gamma_h + mu_h)
  * sigma_v / (sigma_v + mu_v)
  * 1 / mu_v
)
```

注意：

- 该表达式需要在正式论文中根据最终感染力定义重新推导。
- 若 beta_vh 和 beta_hv 已包含叮咬率、蚊人比等因素，R0 表达式需相应调整。
- 全国尺度下蚊媒数量不可观测，建议将蚊人比或 S_v^0/N_h 合并为可估参数或文献固定值。

## 十一、无病平衡点稳定性

理论结论目标：

```text
当 R0 < 1 时，无病平衡点局部渐近稳定；
当 R0 > 1 时，无病平衡点不稳定。
```

证明思路：

- 使用下一代矩阵定理。
- 在无病平衡点处对感染子系统线性化。
- 若谱半径 rho(FV^{-1}) < 1，则感染无法入侵。

## 十二、气候敏感扩展模型

第一版气候扩展建议只改传播率，不同时改太多蚊媒生态参数。

### 方案 A：指数型气候传播率

```text
beta_vh(t) = beta_vh0 * exp(a_T * T_std(t-lag_T) + a_P * P_std(t-lag_P))
```

```text
beta_hv(t) = beta_hv0 * exp(b_T * T_std(t-lag_T) + b_P * P_std(t-lag_P))
```

为减少参数，第一版可先只让 beta_vh(t) 变化，或令 beta_hv(t) 与 beta_vh(t) 共享气候系数。

### 方案 B：线性截断型气候传播率

```text
beta_vh(t) = beta_vh0 * max(0, 1 + a_T * T_std(t-lag_T) + a_P * P_std(t-lag_P))
```

优点：

- 解释直观。

缺点：

- max 函数不可导点可能影响优化。

### 当前建议

第一版采用方案 A：

```text
beta_vh(t) = beta_vh0 * exp(a_T * T_std(t-lag_T) + a_P * P_std(t-lag_P))
```

并固定候选滞后：

```text
lag_T, lag_P in {1, 2, 3, 4} weeks
```

通过模型比较选择滞后组合。

至少比较：

| 模型 | 说明 |

| M0 | 基线常数传播率模型 |

比较指标：
