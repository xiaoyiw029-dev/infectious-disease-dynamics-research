# 参考模型谱系：基线特点与创新综述 v01

更新时间：2026-08-15

用途：帮助确认“巴西全国尺度疾病X动力学模型”的基础假设。本文只总结参考文献中已经出现的模型结构、创新点和对本课题的可借鉴位置，不直接替代最终模型决策。

## 1. 总体判断

现有文献大致可以分为四类。

| 类别 | 代表文献 | 主要模型形态 | 对本课题的作用 |
|---|---|---|---|
| 机制动力学基线模型 | C01, C02, C03, C04, C05 | 人群 SEIR/SIR + 蚊媒 SEI/SI，有些加入无症状、幼蚊阶段或控制项 | 决定基础仓室、传播项、R0 推导和最小二乘拟合的主体结构 |
| 气候机制模型 | C06, C07, C08, C16, C17, C21, C22 | 温度/降雨驱动蚊媒生命史、传播率、滞后效应或适宜性 | 决定气候因子进入模型的位置、函数形式和稳健性分析 |
| 统计预测与空间模型 | C09, C10, C13, C20, C22 | SARIMA、Richards/SIR 映射、Bayesian 空间时间模型、空间回归 | 作为预测性能基线和气候解释的对照方法 |
| 流行病学与数据证据 | C11, C12, C15, C18, C19 | 综述、监测数据描述、血清流行病学、基因组/复发证据 | 支持报告率、免疫、复发、地区异质性和数据处理假设 |

对你的课题最稳妥的基础模型不是“照搬某一篇”，而是采用文献中共同认可的核心结构：人群 SEIR + 蚊媒 SEI，并把创新放在全国真实数据、周尺度观测层、气候解释、区域稳健性和理论分析之间的组合上。

## 2. 机制动力学模型

### C01 Dumont 2008：带幼蚊生态的人群 SEIR + 蚊媒 SEI

模型结构：

- 人群仓室：`S_h, E_h, I_h, R_h`。
- 蚊媒仓室：幼蚊/水生阶段 `L_m`，成蚊 `S_m, E_m, I_m`。
- 传播：感染蚊叮咬易感人，人进入潜伏期；感染人被易感蚊叮咬后蚊进入潜伏期。
- 人群总量近似常数，蚊媒感染后不恢复。
- 幼蚊阶段带环境承载量，体现蚊媒生态和控制。

创新点：

- 把幼蚊生态和传播动力学统一起来。
- 推导正性、疾病消除平衡、基本再生数、稳定性和地方病平衡。
- 使用保持正性的非标准有限差分方法进行数值模拟。

基线特点：

- 数学性强，适合作为理论分析参考。
- 但数据拟合和观测层处理较弱，不是现代真实监测数据预测模型。

对本课题的启发：

- 可借鉴 `SEIR-SEI` 核心结构、R0 推导和正性/稳定性证明方式。
- 幼蚊阶段可以作为扩展，不建议第一版全国模型直接加入。

### C02 Moulay 2011：阶段结构蚊媒生态 + 人群 SIR

模型结构：

- 人群仓室：`S_H, I_H, R_H`，没有人群潜伏期。
- 蚊媒仓室：卵、幼虫/蛹、成蚊，并区分易感成蚊和感染成蚊。
- 蚊媒模型较细，包含卵和幼虫阶段的资源限制。
- 蚊媒没有显式潜伏期，成蚊感染后直接进入感染类。

创新点：

- 对蚊媒种群和病毒传播给出较严格的全局动力学分析。
- 证明阈值、平衡和周期轨道等性质。

基线特点：

- 理论严谨，但感染过程比 CHIKV 周尺度数据Y拟合所需的结构更粗。
- 缺少人和蚊的潜伏期，会削弱峰值时序解释。

对本课题的启发：

- 可作为蚊媒生态理论背景。
- 不建议作为你的基础模型，因为你需要周尺度预测和潜伏期机制。

### C03 Yakob 2013：含无症状的人群模型 + 蚊媒 SEI + 周数据Y拟合

模型结构：

- 人群仓室：`S, E, I, I_a, R`，其中 `I` 为有症状感染，`I_a` 为无症状感染。
- 蚊媒仓室：`X, Y, Z`，分别为易感、潜伏、感染蚊。
- 蚊媒总量简化为稳定状态。
- 用症状比例区分可观察数据Y与总感染。
- 拟合时将新感染经过潜伏/发病延迟后转为周报告数据Y，而不是简单拟合感染人数存量。

创新点：

- 显式纳入无症状感染。
- 对报告数据Y的构造较严谨，区分“模型感染流量”和“监测到的周发病数”。
- 同时做 R0、类型再生数和控制敏感性。

基线特点：

- 很适合指导周尺度真实数据Y拟合。
- 但没有气候驱动，蚊媒种群被简化。

对本课题的启发：

- 观测层应优先参考这篇：周数据Y更应该对应 `E_h -> I_h` 的周流量，而不是 `I_h(t)` 存量。
- 无症状仓室可以作为第一扩展，但不一定放入第一版基础模型。

### C04 Manore 2014：标准人群 SEIR + 蚊媒 SEI 的比较基线

模型结构：

- 人群仓室：`S_h, E_h, I_h, R_h`。
- 蚊媒仓室：`S_v, E_v, I_v`。
- 人群出生死亡平衡，感染恢复后获得长期免疫。
- 蚊媒成虫补充受承载量限制。
- 比较 DENV 与 CHIKV，也比较埃及伊蚊与白纹伊蚊。

创新点：

- 在统一模型框架下比较疾病和媒介差异。
- 系统分析 R0、首次峰值大小、峰值时间、地方病平衡和参数敏感性。

基线特点：

- 是最清晰、最标准、最容易扩展的 `SEIR-SEI` 基线。
- 数学推导、参数解释和敏感性分析都适合借鉴。

对本课题的启发：

- 你的基础仓室最建议从这里出发：`S_h, E_h, I_h, R_h, S_v, E_v, I_v`。
- 后续创新可以逐层添加到这个结构上，而不是一开始建过度复杂模型。

### C05 Dodero-Rojas 2020：巴西里约真实数据拟合 + 控制场景

模型结构：

- 人群仓室：`S, E, I, I_a, R`。
- 蚊媒仓室：`X, Y, Z`。
- 结构接近 C03。
- 使用里约热内卢周报告数据Y进行最小二乘拟合。
- 估计传播率、潜伏率、恢复率等参数，并做控制模拟。

创新点：

- 面向巴西实际疫情数据。
- 比较成蚊控制、孳生地减少、个人防护和联合控制。
- 用蒙特卡洛和敏感性分析评价参数影响。

基线特点：

- 对“巴西 CHIKV + 真实数据拟合”很接近你的选题。
- 但它主要是单城市、分年份拟合。
- 拟合时把感染仓室与周报告数据Y直接对应，观测层严谨性弱于 C03。

对本课题的启发：

- 可作为巴西动力学拟合先例。
- 你的全国尺度和气候解释可以与它形成差异。

## 3. 气候机制模型

### C06 Liu 2020：周期气候驱动的高维延迟模型

模型结构：

- 人群仓室：易感、潜伏、无症状、有症状、住院、恢复。
- 蚊媒仓室：干卵、湿卵、幼虫、易感成蚊、潜伏成蚊、感染成蚊。
- 温度驱动叮咬率、外潜伏期、蚊死亡率、发育率、产卵率等。
- 降雨驱动干卵向湿卵转化。
- 使用周期系数和时变延迟，分析蚊媒再生数和疾病再生数。

创新点：

- 同时考虑温度、降雨、蚊媒发育阶段、时变延迟、无症状和住院。
- 理论上给出蚊媒灭绝、疾病消除和一致持久性条件。

基线特点：

- 数学和机制非常丰富。
- 但参数多、识别难度高，不适合直接作为本科阶段全国周数据Y拟合的第一版。

对本课题的启发：

- 可借鉴“气候作用位置”：温度作用于叮咬率、蚊死亡率、外潜伏期；降雨作用于蚊媒补充或承载量。
- 理论分析可以借鉴其阈值和周期系统语言，但模型应简化。

### C07 Mordecai 2017：温度-传播适宜性机制函数

模型结构：

- 不是仓室传播模型。
- 用温度响应函数构造相对 `R0(T)`。
- 温度影响叮咬率、发育率、成蚊死亡率、外潜伏期、媒介能力等。

创新点：

- 用实验数据拟合非线性温度响应曲线。
- 证明 Aedes 传播适宜性通常呈单峰温度响应。
- 用独立的登革热、疾病X和寨卡数据Y数据做外部验证。

基线特点：

- 适合提供气候函数，不适合单独作为数据Y拟合模型。

对本课题的启发：

- 全国模型可以不一开始估计所有气候-生命史函数，而是先用文献支持的温度非线性形式。

### C08 Huber 2018：季节温度驱动的 SEIR-SEI 模型

模型结构：

- 人群仓室：`S, E, I, R`。
- 蚊媒仓室：`S_v, E_v, I_v`。
- 温度驱动叮咬率、产卵、卵到成虫存活、发育、成虫死亡、外潜伏期和传播概率。
- 季节温度用正弦函数表示。
- 将有症状和无症状感染合并到一个感染仓室。

创新点：

- 把实验温度响应嵌入标准 `SEIR-SEI` 传播模型。
- 研究平均温度和季节振幅对传播窗口的影响。

基线特点：

- 是“标准仓室 + 气候机制”的优雅中间复杂度模型。
- 比 C06 简洁，适合借鉴到你的基础模型扩展中。

对本课题的启发：

- 支持你先采用 `SEIR-SEI`，再让若干关键参数随气候变化。

### C16 Nsoesie 2016 与 C17 Tjaden 2017：气候/环境适宜性模型

模型结构：

- 都不是 ODE 仓室模型。
- C16 使用环境适宜性和机器学习/集成方法预测全球 CHIKV 适宜区。
- C17 使用 Maxent 生态位模型评估当前和未来气候下的传播适宜性。

创新点：

- 强调气候、环境、蚊媒分布和人口暴露共同决定风险。
- 适合做空间风险背景和引言。

基线特点：

- 解释“哪里适合传播”，不能解释“每周数据Y如何变化”。

对本课题的启发：

- 用于支持全国尺度存在地区异质性。
- 不应作为核心动力学方程。

### C21 Ruiz-Moreno 2012：随机气候驱动引入风险模型

模型结构：

- 人群：易感、潜伏、有症状、无症状、恢复。
- 蚊媒：成蚊易感/潜伏/感染，外加卵、幼虫/蛹、滞育卵。
- 温度影响蚊媒生命史、外潜伏期和越冬/滞育。
- 用随机模拟评估病毒输入后的传播风险窗口。

创新点：

- 把随机性、气候驱动、蚊媒生态和病毒引入风险结合。

基线特点：

- 机制细，但场景是美国城市引入风险，不是巴西全国周数据Y拟合。

对本课题的启发：

- 可作为“输入数据Y/初始感染”敏感性分析参考。

### C22 Lowe 2021：巴西水文气象-蚊媒病统计模型

模型结构：

- 研究对象是巴西登革热，不是 CHIKV。
- 使用负二项贝叶斯层级时空模型。
- 使用分布滞后非线性模型处理最低/最高温、干旱指数等气象因子。
- 控制空间、时间、城市化等混杂。

创新点：

- 对气候滞后、非线性和空间时间混杂处理非常成熟。

基线特点：

- 不是传播 ODE，但很适合作为气候解释稳健性参考。

对本课题的启发：

- 你的气候分析最好考虑 0-数周或数月滞后，并加入区域/年份稳健性检验。

## 4. 统计预测与空间模型

### C09 Freitas 2021：里约邻里尺度 Bayesian 空间时间模型

模型结构：

- 不是仓室模型。
- 数据Y数服从 Poisson 分布。
- 线性预测器包含空间随机效应、时间效应、社会经济变量、绿地和温度记忆项。
- 温度影响通过滞后/记忆结构进入。

创新点：

- 在很细的邻里尺度上解释 CHIKV 的空间时间异质性。
- 把气候、社会经济和空间结构同时纳入。

基线特点：

- 解释力强，但没有传染病动力学机制。

对本课题的启发：

- 全国模型必须承认地区差异，否则气候效应可能被空间混杂扭曲。

### C10 Yakob 2022：巴西区域 SARIMA 预测

模型结构：

- 不是仓室模型。
- 按巴西五大区建立月度 SARIMA 模型。
- 使用历史数据Y预测未来数据Y。

创新点：

- 明确做训练集、验证集和未来预测。
- 适合作为真实数据预测的统计基线。

基线特点：

- 预测方便，但没有气候解释和传播机制。

对本课题的启发：

- 你的动力学模型至少要与 SARIMA 或类似时间序列模型比较预测性能。

### C13 Araujo 2025：Richards 曲线 + SIR 参数映射 + 机器学习峰值预测

模型结构：

- 对每个城市/年份拟合 Richards 累计数据Y曲线。
- 将 Richards 参数与 SIR 参数建立一一映射。
- 用气候、数据Y和人口变量预测峰值周。

创新点：

- 可在数千个城市、多个年份自动扫描疫情曲线。
- 将简单曲线模型与 SIR 解释连接。

基线特点：

- 高通量、易部署。
- 但没有蚊媒仓室，也不直接解释人-蚊传播。

对本课题的启发：

- 可以作为全国尺度预测/峰值预测的强对照。
- 也提醒我们：复杂动力学模型必须证明比曲线/机器学习模型多解释了什么。

### C20 Santos 2024：巴西社会脆弱性与空间聚集

模型结构：

- 不是传染动力学模型。
- 使用趋势分析、经验贝叶斯平滑、Moran's I、LISA、空间误差/空间滞后回归。
- 解释社会脆弱性与 CHIKV 空间分布的关系。

创新点：

- 强调社会脆弱性和空间聚集。

基线特点：

- 适合风险解释，不适合模拟传播过程。

对本课题的启发：

- 如果全国模型残差有明显空间聚集，说明基础模型需要区域分层或空间稳健性分析。

## 5. 数据、报告率与流行病学证据

### C11 Almeida 2023

模型结构：没有原始数学模型，主要是对巴西 CHIKV 空间扩张、监测和防控的评论。

对本课题的作用：用于引言，说明巴西 CHIKV 仍是公共卫生问题，全国尺度研究有意义。

### C12 Lima 2023

模型结构：不是仓室模型，结合流行病学、基因组和媒介证据解释巴西 CHIKV 复发。

对本课题的作用：

- 支持“全国单一封闭疫情”假设需要谨慎。
- 支持做地区稳健性、初始免疫或输入数据Y敏感性分析。

### C15 Cavalcanti 2022

模型结构：综述文章，没有动力学方程。

对本课题的作用：

- 支持疾病X自然史设定：潜伏期、症状、恢复和长期免疫。
- 可用于写背景和参数范围来源。

### C18 Anjos 2020

模型结构：血清流行病学横断面研究，不是传播模型。

关键意义：

- 血清阳性人数远高于自报诊断人数，说明报告数据Y不是全部感染。
- 支持在动力学模型中加入报告率或观测比例 `q`。

对本课题的作用：

- 你的模型最好区分“真实感染流量”和“监测报告数据Y”。
- `q` 不宜固定为 1，可做估计或敏感性分析。

### C19 Silva Neto 2022

模型结构：数据描述文章，不是传播模型。

关键意义：

- 提供 SINAN 巴西 arbovirus 数据结构。
- 区分通知周、发病周、最终分类、输入/本地数据Y等字段。

对本课题的作用：

- 决定数据Y数据处理规则。
- 周尺度建模应优先使用发病周而不是通知周；若只能用通知周，需要说明偏差。

## 6. 对基础模型假设的直接影响

| 待确认假设 | 文献支持 | 建议 |
|---|---|---|
| 人群是否用 SEIR | C01, C03, C04, C05, C06, C08, C21 | 建议使用。CHIKV 有潜伏期，SEIR 比 SIR 更适合周尺度拟合 |
| 蚊媒是否用 SEI | C01, C03, C04, C05, C06, C08, C21 | 建议使用。外潜伏期对峰值时序有影响 |
| 是否加入无症状仓室 | C03, C05, C06, C21 支持；C08 合并处理 | 第一版可不加入，作为扩展模型。若加入，需要报告率和可识别性说明 |
| 是否加入幼蚊/卵/幼虫阶段 | C01, C02, C06, C21 支持 | 第一版不建议加入完整幼蚊生态，可用气候驱动的蚊媒补充率或承载量替代 |
| 气候作用在哪些参数 | C06, C07, C08, C21, C22 | 优先作用于叮咬率、蚊死亡率、外潜伏期、蚊媒补充/承载量 |
| 报告数据Y如何连接模型 | C03, C18, C19 | 建议用“周新增感染流量 × 报告率”，不要直接用 `I_h(t)` 代表周数据Y |
| 是否考虑空间异质性 | C09, C10, C12, C13, C20, C22 | 全国第一版可先聚合，但论文中必须做区域稳健性或分区验证 |
| 是否做统计预测对照 | C10, C13 | 建议做。SCI 论文需要证明动力学模型的预测价值 |

## 7. 推荐的第一版基础模型

建议基础模型采用 7 个核心仓室：

```text
Human:    S_h -> E_h -> I_h -> R_h
Mosquito: S_v -> E_v -> I_v
```

基本假设：

1. 研究对象为巴西全国周尺度 CHIKV 报告数据Y。
2. 人群总量在研究期内近似给定，可用年度人口插值。
3. 人感染后经历潜伏期，进入感染期，恢复后获得长期免疫。
4. 蚊媒感染后经历外潜伏期，之后保持感染状态直至死亡。
5. 传播只通过人-蚊-人途径，不考虑直接人传人。
6. 第一版不显式区分无症状感染，但通过报告率 `q` 处理监测数据Y与真实感染之间的差异。
7. 气候因子先不改变仓室结构，而是进入关键参数，例如 `beta_h(t)`, `beta_v(t)`, `mu_v(t)` 或蚊媒补充项。
8. 观测层使用每周新增有症状/可报告感染流量，而不是感染者存量。

这一路线的优点是：基础结构来自多篇文献共同基线，理论分析可做，参数数量可控，后续可自然扩展无症状、气候滞后、区域分层和报告率模型。

## 8. 不建议作为第一版基础模型的做法

| 做法 | 原因 |
|---|---|
| 直接采用 C06 的高维周期延迟模型 | 机制丰富但参数太多，真实周数据Y拟合容易不可识别 |
| 直接采用 C02 的 SIR + 蚊媒生态模型 | 缺少人和蚊潜伏期，不利于 CHIKV 周峰值解释 |
| 只做 SARIMA 或 Richards 曲线 | 预测可行，但缺少传染病动力学和气候机制解释 |
| 一开始加入所有创新点 | 容易导致模型臃肿，参数解释困难，理论分析难写清 |

## 9. 当前最需要你决策的问题

下一步建议只确认三件事：

1. 基础人群模型是否采用 `S_h, E_h, I_h, R_h`。
2. 蚊媒模型是否采用 `S_v, E_v, I_v`，暂不加入卵/幼虫阶段。
3. 无症状感染是否先通过报告率 `q` 间接处理，而不是单独设 `A_h` 仓室。

如果这三点确认，后面就可以正式写“基础模型假设与方程”部分，并把气候扩展作为第二层模型，而不是把所有东西揉进第一版。
