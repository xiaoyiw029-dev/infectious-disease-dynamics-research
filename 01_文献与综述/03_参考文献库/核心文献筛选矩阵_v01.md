## 1. 筛选边界与核验标准

本清单围绕当前研究主线筛选：巴西全国尺度、周数据Y真实数据、气候解释、宿主-媒介动力学、非线性最小二乘拟合、预测验证和严格理论分析。文献必须同时满足以下条件：

1. 可由 DOI、PubMed、PMC、期刊官网或作者机构仓储核验题录；
2. 与研究问题存在直接方法关系，而非只在关键词层面相关；
3. 获取状态单独核验。“开放全文”表示存在合法公开全文入口；“仅摘要”表示本轮只确认到摘要/题录，不能声称已读全文；
4. 预印本和 2026 年新文献不作为本轮核心证据，避免未经充分同行评议或过新的结果主导模型决策。

## 2. 优先级说明

- A：直接决定模型结构、气候函数、参数、拟合或巴西研究定位，建议精读。
- B：支持引言、讨论、数据质量或替代方法比较，建议选读。
- C：扩展路线，当前可暂缓。

## 4. 按作用分类供决策

### 4.1 模型结构与理论分析

首选：C01、C02、C03、C04、C06。

- 若第一版追求可辨识、可拟合、可证明，建议以人群 `SEIR` + 蚊媒 `SEI` 为主，参考 C01/C04。
- 是否增加无症状感染仓室，应由 C03、C06 与巴西观测证据 C18 共同决定，而不是仅因文献常见就加入。
- 若要证明全局稳定性，C02 的方法价值很高；但复杂气候非自治系统的严格证明难度显著高于常系数基线模型。

### 4.2 巴西真实数据拟合与预测基准

首选：C05、C10、C12、C13、C19。

- C10 提供全国/区域 SARIMA 基准，适合设置统计模型对照。
- C05 提供巴西城市尺度宿主-媒介拟合范式。
- C12/C13 说明巴西传播存在多波、再输入、空间异质性；全国单一封闭 ODE 的结论必须谨慎表述。
- C19 是数据Y数据结构和清洗的直接依据。

### 4.3 气候进入模型的方式

首选：C06、C07、C08、C09；辅助：C17、C21、C22。

- “气候解释主线”不应只写 `beta(t)=beta0+alpha*T(t)`。C07/C08 表明温度对多个蚊媒性状通常是非线性、单峰的。
- C06 是温度和降雨直接进入疾病X周期动力学的巴西案例，但模型很复杂，需先检查全国周数据是否足以辨识这些参数。
- C09/C22 支持对温度、降雨采用滞后和非线性效应，并控制季节性/空间混杂。

### 4.4 观测误差、漏报与数据解释

首选：C18、C19、C12。

- 监测数据Y是“被发现并报告的有症状感染”，不等于模型的全部新感染。
- 至少需要报告率或观测比例参数；若该参数与初始易感者、传播率同时自由估计，可能存在不可辨识性。
- 诊断资源短缺、登革热/Zika 共流行、临床误诊和报告延迟应进入限制部分，必要时做敏感性分析。

### 4.5 引言和综述背景

首选：C11、C14、C15、C16、C17、C20。

- C14/C15：疾病、病毒和传播机制。
- C11/C12/C20：巴西疫情演变、空间扩张和社会异质性。
- C16/C17：全球环境适生性与气候变化背景。

## 5. 当前建议的 12 篇“最小必读集”

精读顺序建议：C01 -> C04 -> C03 -> C05 -> C06 -> C07 -> C09 -> C10 -> C12 -> C13 -> C18 -> C19。

其中 C01 和 C06 已由用户提供出版社全文，现可进行逐式精读与数学复现。C14 仍未取得正文，但其作用主要是疾病背景综述，可由 C15 等开放文献补充，不阻塞模型定型。

## 6. 暂不纳入核心集的方向

- 纯最优控制论文：当前研究重点是拟合、预测、气候解释，控制仅作为后续扩展。
- 仅使用机器学习且没有机制解释的疾病X预测：可作为后续预测对照，但不决定第一版动力学模型。
- 2025-2026 年未经充分验证的预印本：保留观察，不作为模型定型依据。
- 仅讨论疫苗或分子机制的论文：除非后续明确加入疫苗仓室或病毒谱系参数，否则不进入核心模型集。

## 7. 需要研究者最终决策的事项

1. 是否把无症状感染设置为独立仓室；
2. 理论部分只证明常系数基线模型，还是挑战周期气候系统的阈值理论；
3. 气候优先作用于有效传播率，还是分别作用于叮咬率、死亡率、EIP 和蚊媒招募；
4. 全国总量模型是否增加五大区域/州级稳健性分析；
5. 预测对照采用 SARIMA，还是 SARIMA 加气候统计模型两层对照。

## 8. 核验入口

- PubMed/PMC：核验医学文献题录、DOI、摘要和开放全文状态。
- PLOS、CDC、Royal Society、MDPI、Nature/Scientific Data：开放原文及补充材料。

- ScienceDirect：用于核验 Elsevier 文献题录、摘要和方法信息；没有开放全文时明确标为需权限。
