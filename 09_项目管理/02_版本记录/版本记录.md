### 4. 确定疾病消除平衡点并推导 R0
- 新增文件：`疾病消除平衡点与基本再生数_R0_v01.md`
- 确定疾病消除平衡点 DFE：
  `E0 = (S_h^0, 0, 0, R_h^0, Lambda_v/mu_v, 0, 0)`
- 在无既往免疫假设下，得到：
  `E0 = (N_h, 0, 0, 0, Lambda_v/mu_v, 0, 0)`
- 使用下一代矩阵法推导当前基础模型的基本再生数：
  `R0 = sqrt(beta_h beta_v sigma_v / [gamma_h mu_v (sigma_v + mu_v)])`
- 明确说明：由于当前感染力采用感染蚊媒比例形式，R0 中不显式出现蚊媒平衡数量，这是模型设定导致的合理结果。
