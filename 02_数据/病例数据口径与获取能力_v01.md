# 数据Y数据口径与获取能力_v01

记录日期：2026-08-25

本文件用于回答本课题当前最关键的数据问题：巴西疾病X数据Y数据应从哪里准确获取、可获取到什么粒度、probable cases 和 confirmed cases 是否都能支持建模。

## 一、当前核查结论

首选主数据源应为巴西官方 OpenDataSUS / SINAN 数据集：

```text
https://dadosabertos.saude.gov.br/dataset/arboviroses-febre-de-chikungunya
```

该数据集由巴西卫生部相关监测部门发布，来源为 Sinan Online。官方页面显示资源包括数据字典和 Arboviroses - Febre de Chikungunya CSV 数据。页面注明：

1. 2014-2023 年数据覆盖第 1-52 流行病学周。
2. 2024-2026 年数据覆盖第 1-33 流行病学周。
3. 数据集页面最近更新为 2026-08-15。
4. 官方说明中，casos prováveis 应理解为所有已通知数据Y中排除 descartados 的数据Y。

因此，本课题可以准确获取巴西全国尺度的疾病X数据Y数据，并可以进一步汇总为周尺度时间序列。

## 二、推荐数据口径

第一主分析建议使用：

```text
weekly probable chikungunya cases in Brazil
```

中文表述：

```text
巴西全国周尺度疾病X可能数据Y数
```

理由：

1. probable cases 是巴西官方监测面板和流行病学报告中常用的公共卫生监测口径。
2. 相比 confirmed cases，probable cases 更接近真实传播趋势，因为 confirmed cases 受检测能力、实验室资源、地区差异和年度政策变化影响更大。
3. 当前模型拟合的是真实传播过程通过观测层进入报告数据Y的动态，probable cases 更适合作为第一版拟合对象。
4. confirmed cases 可作为敏感性分析或补充分析，不建议作为第一主结果。

## 三、可获取程度

根据官方数据集页面、API 页面和 2026 年 CSV 样例，目前可以较稳妥判断可获取到以下层级。

| 维度 | 可获取程度 | 当前判断 |
|---|---|---|
| 时间范围 | 2014-2026 | 2026 年截至第 33 流行病学周，属于不完整年度 |
| 时间粒度 | 日和周均可支持 | 2026 样例已确认存在 `DT_NOTIFIC`、`SEM_NOT`、`DT_SIN_PRI`、`SEM_PRI` |
| 空间粒度 | 全国、州、市镇 | 2026 样例已确认存在 `SG_UF` 和 `ID_MN_RESI`，覆盖 27 个居住州和 2631 个居住市镇 |
| 数据Y分类 | probable / discarded / confirmed 相关分类 | probable 可由排除 discarded 得到，confirmed 需要依据数据Y分类或确认标准字段进一步核查 |
| 个体变量 | 年龄、性别、结局等 | SINAN 数据字典显示同类字段存在，但本课题只在需要描述性统计时使用 |
| 文件形式 | CSV、数据字典、API | 官方页面列出 CSV 和数据字典，API 页面可作为程序化获取入口 |

## 四、关键字段预期

2026 年样例已确认存在以下关键字段；历史年度是否完全一致，仍需下载 2014-2025 年后核查：

| 字段类型 | 可能用途 | 需要确认的问题 |
|---|---|---|
| `DT_NOTIFIC` | 构造报告日期或报告周 | 历史年度字段一致性 |
| `DT_SIN_PRI` | 构造症状开始日期或发病周 | 历史年度字段一致性 |
| `SEM_NOT` | 构造通知周序列 | 与 `SEM_PRI` 的差异 |
| `SEM_PRI` | 构造症状开始周序列 | 当前主时间轴候选 |
| `SG_UF` | 全国汇总、州级稳健性 | 历史年度字段完整率 |
| `ID_MN_RESI` | 市镇级汇总和人口匹配 | 与 IBGE 代码是否直接对齐 |
| `CLASSI_FIN` | probable / confirmed / discarded 口径 | discarded 和 confirmed 的编码必须由数据字典确认 |
| `CRITERIO` | laboratory / clinical-epidemiological 等确认标准 | confirmed cases 是否能稳定提取 |
| 结局 | 死亡或严重程度描述 | 非主模型变量，可用于背景描述 |

## 五、probable cases 与 confirmed cases 的实际区别

probable cases：

1. 更偏向监测口径。
2. 通常包含疑似数据Y中未被排除者。
3. 数量更多，时间序列更连续。
4. 更适合拟合全国传播趋势。
5. 缺点是可能包含少量非疾病X数据Y，尤其在登革热、寨卡等共同流行地区。

confirmed cases：

1. 更偏向诊断确认口径。
2. 可以由实验室标准或临床-流行病学标准确认。
3. 特异性更高。
4. 缺点是强烈受检测能力、检测策略、地区医疗资源和年份政策影响。
5. 如果直接用于动力学拟合，可能把检测变化误当成传播变化。

当前建议：

1. 主模型拟合使用 probable cases。
2. confirmed cases 作为补充描述或敏感性分析。
3. 如果 confirmed 字段缺失率高或跨年编码不稳定，则只用于背景，不进入主拟合。

## 六、可作为交叉验证的数据源

### 1. 巴西卫生部 Arboviroses 监测面板

入口：

```text
https://www.gov.br/saude/pt-br/assuntos/saude-de-a-a-z/a/aedes-aegypti/monitoramento-das-arboviroses
```

用途：

1. 核对全国年度或近期累计数据Y数量。
2. 查看官方实时趋势。
3. 辅助确认当前年度是否存在明显回填或更新。

限制：

1. 面板主要用于监测展示，不一定方便复现实证分析。
2. 面板口径可能随实时更新改变。
3. 论文主数据仍应以可下载、可保存、可复现的 OpenDataSUS/SINAN 文件为准。

### 2. PAHO/WHO 区域监测信息

PAHO 区域信息可用于美洲背景和巴西总量趋势交叉验证。PAHO 2026 年页面和相关资料区分 reported cases 与 confirmed cases，并强调 2025 年以来美洲地区疾病X再次上升。

用途：

1. 写研究背景。
2. 说明巴西在美洲地区数据Y负担中的重要性。
3. 与巴西官方全国总量做外部一致性检查。

限制：

1. 粒度通常不如巴西本国 SINAN 数据。
2. 不建议作为本课题主拟合数据。

## 七、当前不能完全确定的事项

以下事项必须在下载数据字典和样例数据后再最终决定：

1. 第一主时间轴最终用 `SEM_PRI` 还是 `SEM_NOT`。
2. `CLASSI_FIN=5` 是否为 discarded 的正式编码。
3. `CLASSI_FIN=13` 是否为 chikungunya final classification 的正式编码。
4. `CRITERIO` 中 1、2、3 的准确含义。
5. 2024-2026 年数据是否与 2014-2023 年字段完全一致。
6. 2026 年数据是否纳入正式拟合，或只作为外推验证和更新预测。

## 八、当前建议决策

建议当前论文数据口径先定为：

```text
使用 OpenDataSUS/SINAN 的巴西疾病X数据Y数据，以全国周尺度 probable cases 作为主拟合数据Y序列；confirmed cases 仅在字段质量允许时作为敏感性分析。
```

建议下一步数据工作：

1. 下载 OpenDataSUS 数据字典。
2. 下载 2014-2026 年数据Y CSV 或通过 API 获取。
3. 先抽取 2023-2026 年样例检查字段。
4. 明确症状开始周、通知周、数据Y分类、确认标准、居住地字段。
5. 形成 `数据Y数据字段核查表_v01.md`。
6. 再由负责人决定主时间轴和是否纳入 2026 年不完整数据。
