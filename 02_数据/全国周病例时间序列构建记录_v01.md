## 二、数据来源

原始数据Y数据来源为 OpenDataSUS/SINAN 疾病X年度 CSV。

本轮使用：

```text
CHIKBR15.csv 至 CHIKBR26.csv
```

未纳入：

```text
CHIKBR14.csv
```

原因：2014 年按同一官方 S3 年度 CSV 路径访问时返回 AccessDenied，暂不纳入第一版主分析。

## 三、数据Y口径

主数据Y口径：

```text
probable cases = 所有通知数据Y - discarded 数据Y
```

程序操作定义：

```text
CLASSI_FIN != 5
```

同时保留补充口径：

| 字段 | 含义 |
|---|---|
| `notifications_total` | 当周总通知记录数 |
| `cases` | 主模型使用数据Y数，等于 probable cases |
| `probable_cases` | probable cases，与 `cases` 相同 |
| `discarded_cases` | `CLASSI_FIN=5` |
| `chikungunya_classified_cases` | `CLASSI_FIN=13` |
| `confirmed_chikungunya_cases` | `CLASSI_FIN=13` 且 `CRITERIO` 为 1 或 2 |

## 四、时间轴

主时间字段：

```text
DT_SIN_PRI
```

含义：症状开始日期。

分周方法：

1. 使用症状开始日期，而不是通知日期。
2. 将日期转换为 Sunday-start 流行病学周。
3. 第 1 周定义为包含 1 月 4 日的那一周。
4. 输出周开始日期和周结束日期。

采用该方法的原因：

1. 症状开始日期更接近真实发病过程。
2. 原始 `SEM_PRI` 在早期年份存在少量异常编码或格式不稳定。
3. 使用 `DT_SIN_PRI` 重建周序列更可复现。

## 五、时间范围

最终输出范围：

```text
2015-W01 至 2026-W31
```

对应日期：

```text
2015-01-04 至 2026-08-08
```

说明：

2015 年 1 月 1-3 日在 Sunday-start 流行病学周定义下属于 2014-W53。由于当前没有纳入 2014 年完整数据，该不完整首周未放入主分析序列。

2026 年最新周为 2026-W31，原因是当前下载数据中 `DT_SIN_PRI` 最新日期为 2026-08-08。OpenDataSUS 页面提到 2026 年覆盖至第 33 流行病学周，可能对应数据更新或通知覆盖口径，不等于症状开始日期重建后的最新完整周。

## 八、质量控制说明

已生成年度质量控制表：

```text
02_数据/04_数据质量控制/brazil_weekly_chikungunya_cases_quality_summary.csv
```

该表记录：

1. 每年原始记录数。
2. 保留记录数。
3. 因症状开始日期缺失、无法解析或超出研究时间范围而排除的记录数。
4. `DT_SIN_PRI` 缺失数。
5. `DT_NOTIFIC` 缺失数。
6. 原始 `SEM_PRI` 与重建周的一致性。
7. 居住州和居住市镇取值数量。
