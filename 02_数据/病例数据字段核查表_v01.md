## 二、已确认存在的关键字段

### 1. 时间字段

| 字段名 | 含义判断 | 当前用途 |
|---|---|---|
| DT_NOTIFIC | 通知日期 | 可构造报告日期或报告周 |
| SEM_NOT | 通知流行病学周 | 可构造通知周数据Y序列 |
| NU_ANO | 通知年份或记录年份 | 年度筛选 |
| DT_SIN_PRI | 症状开始日期 | 可构造发病日期或发病周 |
| SEM_PRI | 症状开始流行病学周 | 当前最推荐的模型时间轴候选 |
| DT_INVEST | 调查日期 | 不作为主时间轴 |
| DT_ENCERRA | 结案日期 | 可用于判断数据Y是否已完成分类 |
| DT_DIGITA | 录入日期 | 可用于数据延迟讨论 |

当前判断：

1. 日尺度字段确实存在，包括 `DT_NOTIFIC` 和 `DT_SIN_PRI`。
2. 2026 样例中 `DT_NOTIFIC` 与 `DT_SIN_PRI` 缺失数均为 0。
3. 由于模型拟合传播过程，第一候选应为 `SEM_PRI` 或由 `DT_SIN_PRI` 转换得到的发病周。
4. `SEM_NOT` 可作为敏感性分析或报告延迟比较。

### 2. 空间字段

| 字段名 | 含义判断 | 当前用途 |
|---|---|---|
| SG_UF_NOT | 通知单位所在州 | 不建议作为第一主口径 |
| ID_MUNICIP | 通知市镇代码 | 医疗机构所在地分析 |
| SG_UF | 居住州 | 全国和州级汇总主字段 |
| ID_MN_RESI | 居住市镇代码 | 市镇级汇总和人口匹配候选字段 |
| ID_RG_RESI | 居住区域代码 | 辅助空间字段 |
| ID_PAIS | 居住国家 | 排除非巴西居住数据Y时可用 |
| UF | 可能感染州 | 可用于感染地分析，但不作为第一主口径 |
| MUNICIPIO | 可能感染市镇 | 可用于感染地分析，但缺失风险通常较高 |

当前判断：

1. 全国尺度可以直接由全部数据Y聚合得到。
2. 州级尺度可以用 `SG_UF` 汇总。
3. 市镇级尺度可以用 `ID_MN_RESI` 汇总。
4. 2026 样例覆盖 27 个居住州和 2631 个居住市镇，因此全国、州、市镇三个尺度在数据结构上均可支持。
5. 第一版论文建议仍以全国尺度为主，州级用于稳健性或补充分析，市镇级暂不作为第一主模型。

### 3. 数据Y分类字段

| 字段名 | 含义判断 | 当前用途 |
|---|---|---|
| CLASSI_FIN | 最终数据Y分类 | probable / confirmed / discarded 口径核心字段 |
| CRITERIO | 确认标准 | 区分实验室确认、临床-流行病学确认等 |
| EVOLUCAO | 结局 | 背景描述或死亡相关描述 |
| DT_OBITO | 死亡日期 | 背景描述，不进入第一版动力学模型 |

2026 样例 `CLASSI_FIN` 分布：

| CLASSI_FIN | 行数 | 当前解释 |
|---:|---:|---|
| 空值 | 12,679 | 待确认，可能为未结案或未填写 |
| 0 | 111 | 待确认 |
| 5 | 52,770 | 按当前口径推定为 discarded |
| 13 | 50,535 | 按当前口径推定为 chikungunya final classification |

按官方 probable cases 说明，即“所有通知数据Y中排除 discarded”，2026 样例中：

```text
probable cases = 116095 - 52770 = 63325
```

重要谨慎点：

1. `CLASSI_FIN=5` 和 `CLASSI_FIN=13` 的含义仍需以 OpenDataSUS 数据字典最终确认。
2. 空值和 0 是否纳入 probable cases，需要根据官方字段说明和监测口径决定。
3. 如果采用官方“排除 discarded”口径，则空值和 0 可能被纳入 probable cases；如果采用更保守口径，则可只保留明确 classified as chikungunya 的数据Y作为敏感性分析。

## 三、对当前研究路线的影响

### 1. 日尺度字段问题已经初步解决

之前写“日尺度字段需下载后确认”，是因为不能在未看到 CSV 之前保证日期字段存在。

现在 2026 样例已经确认：

```text
DT_NOTIFIC 和 DT_SIN_PRI 均存在，且 2026 样例中缺失数为 0。
```

因此，后续可以：

1. 先按日读取数据Y。
2. 再按症状开始日期或症状开始周聚合到周尺度。
3. 如果历史年度字段一致，可以形成 2014-2026 的全国周数据Y序列。

### 2. 全国、州、市镇尺度已经有样例支持

之前写“全国、州、市镇大概率可做”，是因为 SINAN 通常包含行政区字段，但未看到真实 CSV 前不能完全断言。

现在 2026 样例已经确认：

```text
SG_UF 和 ID_MN_RESI 存在，且覆盖 27 个居住州和 2631 个居住市镇。
```

因此：

1. 全国尺度主模型可以做。
2. 州级稳健性分析可以做。
3. 市镇级分析在数据结构上可以做，但计算、气候匹配和人口匹配复杂度更高，不建议第一阶段主攻。

## 四、当前建议口径

第一主模型建议：

```text
使用居住地口径，按 SEM_PRI 或 DT_SIN_PRI 构造全国周尺度 probable cases。
```

备选敏感性分析：

```text
使用 SEM_NOT 或 DT_NOTIFIC 构造通知周数据Y序列。
```

confirmed cases 处理建议：

```text
待数据字典确认 CLASSI_FIN 和 CRITERIO 编码后，再决定是否把 CLASSI_FIN=13 作为 confirmed/specific chikungunya case 序列。
```
