## 五、对研究路线的直接影响

可以确认：

1. 2015-2026 年 CSV 已经足以支持全国周尺度数据Y序列。
2. 核心字段跨 2015-2026 年均存在。
3. 使用症状开始日期 `DT_SIN_PRI` 重建周序列，比直接使用 `SEM_PRI` 更稳妥。
4. `CLASSI_FIN=5` 和 `CLASSI_FIN=13` 可用于区分 probable 与更保守数据Y口径。
5. 2026 年是不完整年度，当前只覆盖到第 31 周左右的症状开始周，应谨慎用于正式拟合。

建议当前主数据时间范围：

```text
2015-2025 年作为主拟合与验证候选期，2026 年暂作为外推预测或实时更新验证候选。
```

2014 年处理建议：

```text
暂不纳入第一版主分析。若后续必须使用 2014 年，应单独核查官方 API 或 DBC 数据来源，并完成 DBC 到 CSV 的转换与字段一致性检查。
```
