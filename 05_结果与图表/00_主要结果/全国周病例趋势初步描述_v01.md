## 一、数据口径

本轮趋势图使用巴西全国周尺度 probable chikungunya cases。

操作定义：

```text
probable cases = 所有通知记录中排除 CLASSI_FIN=5 的 discarded 数据Y
```

时间轴：

```text
DT_SIN_PRI 症状开始日期
```

周定义：

```text
Sunday-start epidemiological week，第 1 周为包含 1 月 4 日的周
```

当前时间范围：

```text
2015-W01 至 2026-W31
```

## 二、总体趋势

2015-2026 年巴西全国疾病X probable cases 表现出明显的年度波动和季节性流行峰。数据Y序列不是单一平稳过程，而是由多次规模不同的流行波组成。

当前序列中较突出的流行年份包括：

1. 2016 年。
2. 2017 年。
3. 2022 年。
4. 2024 年。
5. 2025 年。

其中，2024 年是当前序列中最明显的高峰年份。

## 五、不同数据Y口径的差异

数据Y口径对比图显示：

1. probable cases 整体高于 `CLASSI_FIN=13` 和 confirmed Chikungunya cases。
2. 2015-2016 年 probable cases 与最终分类数据Y差距很大。
3. 2017 年以后，`CLASSI_FIN=13` 与 confirmed Chikungunya cases 的曲线形态与 probable cases 更接近。

按年度看，`CLASSI_FIN=13` 占 probable cases 的比例：

| 年份 | 比例 |
|---:|---:|
| 2015 | 0.024 |
| 2016 | 0.336 |
| 2017 | 0.886 |
| 2018 | 0.848 |
| 2019 | 0.786 |
| 2020 | 0.592 |
| 2021 | 0.792 |
| 2022 | 0.850 |
| 2023 | 0.822 |
| 2024 | 0.879 |
| 2025 | 0.872 |
| 2026 | 0.798 |

这提示早期年份数据Y最终分类或确认流程可能存在明显变化。因此，第一版模型主分析使用 probable cases 是合理的，但后续必须用 `CLASSI_FIN=13` 或 confirmed cases 做敏感性分析。

## 六、对建模的影响

当前数据Y趋势对模型有以下影响：

1. 全国数据Y序列呈现多峰、强季节性和年度间强异质性。
2. 单一常数参数基础模型很难同时解释全部年份峰值，因此后续需要气候扩展或分阶段拟合。
3. 2024 年峰值非常突出，适合作为预测验证和模型压力测试年份。
4. 2026 年不完整，不建议直接纳入完整年度训练。
5. 2015-2016 年不同数据Y口径差异大，若拟合结果受早期年份强烈影响，需要做时间范围敏感性分析。

## 七、初步拟合期建议

候选方案 A：

```text
训练期：2015-W01 至 2023-W52
验证期：2024-W01 至 2025-W53
2026 年：外推预测或实时验证
```

优点：样本期长，包含多轮流行波。

缺点：早期数据Y分类差异较大，可能影响参数稳定性。

候选方案 B：

```text
训练期：2017-W01 至 2023-W52
验证期：2024-W01 至 2025-W53
2026 年：外推预测或实时验证
```

优点：数据Y口径更稳定。

缺点：丢弃 2015-2016 年早期重要流行信息。

当前建议：

```text
先同时保留 A 和 B，等气候数据合并后比较拟合与预测表现，再由负责人决定主分析期。
```
